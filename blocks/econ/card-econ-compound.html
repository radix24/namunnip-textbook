이자에 이자가 붙으면 돈은 언제 두 배가 될까?

단리와 복리 · 시뮬레이션

  1. 질문100만 원을 연이율 6%로 맡기면 30년 뒤 얼마가 될까요? 이자를 원금에만 붙이는 것과 이자에도 이자를 붙이는 것은 얼마나 차이가 날까요?
  2. 복원등차수열 \(a_n = a + nd\)는 일정하게 더하고, 등비수열 \(a_n = ar^n\)은 일정하게 곱합니다.
  3. 설명단리는 원금에만 이자가 붙어 \(S = P(1 + rn)\)로 일정하게 늘어납니다(등차수열). 복리는 이자도 원금에 더해 다음 이자를 낳으므로 \(S = P(1 + r)^n\)으로 일정한 비율로 늘어납니다(등비수열). 1년을 \(m\)번 나누어 복리로 계산하면 \(P\left(1 + \frac{r}{m}\right)^{mn}\)이고, \(m\)을 한없이 키우면 \(Pe^{rn}\)(연속 복리)에 가까워집니다.
  4. 연결돈이 두 배가 되는 기간은 \((1 + r)^n = 2\), 곧 \(n = \frac{\log 2}{\log(1 + r)}\)이고, 이율을 % 단위로 \(R\)이라 하면 대략 \(\frac{72}{R}\)년입니다(72의 법칙). 물가가 연 3%씩 오르면 약 24년 뒤 물가가 두 배가 된다는 것도 같은 계산입니다.
  5. 적용이율을 바꾸며 실제로 두 배가 되는 때와 \(72/R\)을 비교하세요. 72의 법칙은 이율이 몇 %일 때 가장 잘 맞나요? 복리 주기를 바꾸면 결과가 얼마나 달라지나요?
  6. 판단복리 주기를 하루로 줄여도 원리합계는 한없이 커지지 않고 \(Pe^{rn}\)을 넘지 않습니다. 또 대출에도 복리가 적용되므로, 갚지 않은 이자는 빚을 같은 방식으로 불립니다.
