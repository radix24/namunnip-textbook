그림 위를 가로로 끌어도 점이 움직입니다. 점을 천천히 움직이면 아래 칸에 기울기의 자취가 남습니다. 자취를 다 그린 뒤 공식과 겹쳐 보세요.

  1. 질문\(\sec x = \frac{1}{\cos x}\)의 그래프는 U자 모양을 되풀이합니다. 이 곡선의 접선 기울기는 어디에서 0이고, 어디에서 가파를까요? 기울기를 모은 그래프는 어떤 식일까요?
  2. 복원몫의 미분법 \(\left(\frac{1}{g}\right)' = -\frac{g'}{g^2}\)과 역함수의 미분법 \(\frac{dy}{dx} = \frac{1}{\,dx/dy\,}\), \((\sin x)' = \cos x\), \((\cos x)' = -\sin x\), \((\tan x)' = \sec^2 x\)를 씁니다.
  3. 설명몫의 미분법으로 \((\sec x)' = \frac{\sin x}{\cos^2 x} = \sec x\tan x\), \((\csc x)' = -\csc x\cot x\), \((\cot x)' = -\csc^2 x\)입니다. 역함수는 거꾸로 생각합니다. \(y = \arcsin x\)이면 \(x = \sin y\)이므로 \(\frac{dx}{dy} = \cos y = \sqrt{1 - x^2}\) (\(-\frac{\pi}{2} \le y \le \frac{\pi}{2}\)에서 \(\cos y \ge 0\))이고, 따라서 \((\arcsin x)' = \frac{1}{\sqrt{1 - x^2}}\)입니다. 같은 방법으로 \(x = \tan y\)에서 \((\arctan x)' = \frac{1}{1 + x^2}\)입니다.
  4. 연결\((\arctan x)' = \frac{1}{1 + x^2}\)를 거꾸로 읽으면 \(\int \frac{dx}{1 + x^2} = \arctan x + C\)입니다. 삼각함수가 전혀 없는 분수식의 적분에서 역삼각함수가 나오는 이유입니다. 다음 카드의 미술관 문제는 이 도함수를 실제로 씁니다.
  5. 적용\(\sec x\)에서 점을 천천히 움직여 자취를 그리세요. 자취가 0을 지나는 곳은 원래 그래프의 어디인가요? 공식을 겹쳐 맞는지 확인한 뒤, 다섯 함수를 모두 해 보세요. \(\arcsin x\)의 기울기는 \(x = \pm 1\) 근처에서 어떻게 되나요?
  6. 판단\((\arcsin x)'\)를 구할 때 \(\cos y = \pm\sqrt{1 - x^2}\)에서 양의 부호만 고른 것은 \(\arcsin\)의 치역 \(\left[-\frac{\pi}{2}, \frac{\pi}{2}\right]\) 때문입니다. 치역을 잊으면 부호를 정할 수 없습니다. 또 \(x = \pm 1\)에서는 접선이 세로가 되어 미분계수가 없습니다.
