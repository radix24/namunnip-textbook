수학 실험

수학 실험은 직접 해 보거나 컴퓨터로 시뮬레이션해 수학적 사실을 확인하거나 값을 어림하는 탐구입니다. 실험 결과는 우연에 따라 흔들리므로, 몇 번 실험할지 정하고 결과가 얼마나 흔들리는지 함께 보고해야 합니다. 이 절에서는 확률 실험으로 π를 어림하고 실험 횟수의 의미를 따져 봅니다.

먼저 알면 좋은 것 독립시행의 확률표본비율의 분포

  2. 2.3.2실험을 몇 번 해야 믿을 만할까 — 횟수와 흔들림(1/√n)

2.3.1

평행선 위에 바늘을 떨어뜨리기만 해서 원주율 π를 구할 수 있을까?

수학 실험 · 시뮬레이션

  1. 질문간격이 \(d\)인 평행선이 그어진 바닥에 길이 \(l\)(\(l \le d\))인 바늘을 마구 떨어뜨립니다. 바늘이 선에 걸칠 확률은 얼마이고, 이 실험으로 π를 어림할 수 있을까요?
  2. 복원기하적 확률, 정적분 \(\int_0^{\pi} \sin\theta \, d\theta = 2\).
  3. 설명바늘이 선과 이루는 각을 \(\theta\), 바늘 중점과 가장 가까운 선 사이 거리를 \(x\)라 하면, \(x \le \frac{l}{2}\sin\theta\)일 때 걸칩니다. 이를 계산하면 걸칠 확률은 \(\frac{2l}{\pi d}\)입니다. 따라서 \(N\)개 중 \(H\)개가 걸쳤다면 \(\pi \approx \frac{2lN}{dH}\)로 어림할 수 있습니다. 18세기 뷔퐁이 제시한 문제로, 실험으로 수학 상수를 추정하는 수학 실험의 고전적인 예입니다.
  4. 연결난수를 이용해 값을 어림하는 방법을 몬테카를로 방법이라 하며, 물리, 금융, 인공지능 등에서 널리 쓰입니다.
  5. 적용10개, 100개, 1000개를 떨어뜨리며 π의 어림값이 어떻게 바뀌는지 기록하세요. 실제로 성냥개비와 공책으로 해 보고 결과를 비교해 보세요.
  6. 판단실험 횟수가 적으면 어림값이 크게 흔들립니다. 실험 결과를 보고할 때는 횟수와 함께 결과가 얼마나 흔들리는지(다음 카드)를 밝혀야 합니다.

확인조건이 달라지면

\(l = d\)일 때 바늘 100개 중 64개가 선에 걸쳤습니다. π의 어림값은?

2.3.2

주사위 두 개의 합이 7일 확률을 실험으로 구한다면, 몇 번 던져야 할까?

실험 횟수와 오차 · 시뮬레이션

횟수마다 같은 실험을 40모둠이 각자 했다고 생각하고, 모둠별 상대도수를 점으로 찍습니다.

  1. 질문모둠마다 주사위를 던져 합이 7인 비율을 구했더니 결과가 제각각입니다. 실험 횟수를 몇 배로 늘려야 결과가 믿을 만해질까요?
  2. 복원큰 수의 법칙, 표본비율의 표준편차 \(\sqrt{\frac{p(1 - p)}{n}}\).
  3. 설명합이 7일 확률은 \(\frac{6}{36} = \frac16\)입니다. 실험 횟수 \(n\)이 커질수록 상대도수는 \(\frac16\)에 가까워지지만, 흩어진 정도는 \(\sqrt{\frac{p(1 - p)}{n}}\)처럼 \(\frac{1}{\sqrt n}\)에 비례해 줄어듭니다. 그래서 흔들림을 절반으로 줄이려면 횟수를 4배, 10분의 1로 줄이려면 100배 늘려야 합니다. 수학 실험을 설계할 때는 원하는 정확도에 맞춰 횟수를 미리 정합니다.
  4. 연결앞 카드의 뷔퐁의 바늘 실험도 같습니다. π를 소수 둘째 자리까지 믿을 만하게 얻으려면 매우 많은 횟수가 필요합니다.
  5. 적용점들이 흩어진 폭이 횟수에 따라 어떻게 줄어드는지 보세요. 10번과 1000번의 폭은 대략 몇 배 차이인가요?
  6. 판단실험이 잘못 설계되었다면(주사위가 찌그러졌거나 기록이 틀렸다면) 횟수를 늘려도 엉뚱한 값으로 모일 뿐입니다. 횟수는 우연한 오차만 줄입니다.
