1.7.1

이 적분은 어떤 방법으로 풀어야 할까?

여러 가지 적분법 · 도전

1 / 8점수 0

—

처음 고른 답으로 점수를 매깁니다. 방법이 둘 이상 통하는 문제는 가장 짧은 길을 정답으로 하고, 다른 길도 설명에 적었습니다.

  1. 질문미분은 규칙만 따르면 어떤 식이든 계산이 끝납니다. 그런데 적분은 같은 모양처럼 보이는 \(\int x e^{x^2}dx\)와 \(\int x e^x dx\)도 푸는 방법이 전혀 다릅니다. 무엇을 보고 방법을 고를까요?
  2. 복원치환적분은 합성함수의 미분법을, 부분적분은 곱의 미분법을 거꾸로 쓴 것입니다. 분수식은 간단한 분수의 합으로 쪼갤 수 있고, \(\sqrt{a^2 - x^2}\)은 \(x = a\sin\theta\)로 바꾸면 근호가 사라집니다.
  3. 설명식에서 먼저 찾을 신호는 네 가지입니다. ① 어떤 식과 그 도함수가 함께 있다 → 치환적분 (\(x e^{x^2}\)에서 \(x^2\)과 \(2x\)). ② 성격이 다른 두 함수의 곱이다 → 부분적분 (\(x e^x\), \(\ln x = 1 \cdot \ln x\)). ③ 분모가 인수분해되는 분수식이다 → 부분분수. ④ \(\sqrt{a^2 - x^2}\)이 있다 → 삼각치환. 어느 신호도 없고 표의 꼴과 같으면 공식을 그대로 씁니다.
  4. 연결방법을 고른 뒤에도 미분해서 원래 식이 나오는지 확인하는 습관이 중요합니다. 적분은 거꾸로 가는 계산이라 실수를 확인할 방법이 미분뿐입니다.
  5. 적용여덟 문제에서 신호를 찾아 방법을 고르세요. 틀린 문제는 설명을 읽고 어떤 신호를 놓쳤는지 확인하세요. 문제 7은 분자가 분모의 도함수라는 신호가 숨어 있습니다.
  6. 판단신호가 둘 이상인 식도 있습니다. \(\int\frac{2x + 3}{x^2 + 3x + 2}dx\)는 부분분수로도 풀리지만 치환이 훨씬 짧습니다. 또 \(e^{x^2}\)처럼 어떤 방법으로도 기본 함수로 적분할 수 없는 식이 있다는 것도 알아 두어야 합니다.

1.7.2

복잡한 분수식을 간단한 분수 두 개로 쪼갤 수 있을까?

부분분수 · 조작

—

  1. 질문\(\int\frac{1}{x^2 - 1}dx\)는 치환도 부분적분도 통하지 않습니다. 하지만 \(\int\frac{1}{x - 1}dx = \ln|x - 1| + C\)는 바로 할 수 있습니다. 복잡한 분수를 이런 간단한 분수의 합으로 바꿀 수 있다면 어떨까요?
  2. 복원통분은 \(\frac{A}{x - a} + \frac{B}{x - b} = \frac{A(x - b) + B(x - a)}{(x - a)(x - b)}\)입니다. 항등식은 모든 \(x\)에서 성립하므로 아무 값이나 넣어도 됩니다.
  3. 설명통분을 거꾸로 하는 것이 부분분수 분해입니다. \(\frac{px + q}{(x - a)(x - b)} = \frac{A}{x - a} + \frac{B}{x - b}\)에서 양변에 \((x - a)(x - b)\)를 곱하면 \(px + q = A(x - b) + B(x - a)\)이고, 이것은 항등식이므로 \(x = a\)를 넣으면 \(B\)가 사라져 \(A = \frac{pa + q}{a - b}\), \(x = b\)를 넣으면 \(B = \frac{pb + q}{b - a}\)입니다. 원래 식에서 \(x - a\)를 손으로 가리고 나머지에 \(x = a\)를 넣는 것과 같아 "가림 방법"이라고도 합니다. 그러면 \(\int\frac{px + q}{(x - a)(x - b)}dx = A\ln|x - a| + B\ln|x - b| + C\)입니다.
  4. 연결그래프로 보면 원래 함수의 점근선 \(x = a\), \(x = b\) 근처에서의 모양은 각각 \(\frac{A}{x - a}\), \(\frac{B}{x - b}\)가 정합니다. 분해는 "어느 점근선 근처에서 얼마나 세게 튀는가"를 나눠 적은 것입니다. 이 방법은 로지스틱 미분방정식을 풀 때도 다시 쓰입니다.
  5. 적용\(A\)와 \(B\)를 움직여 색 곡선을 회색 곡선에 정확히 겹쳐 보세요. 먼저 한 점근선 근처만 맞추고 다른 쪽을 맞추면 쉽습니다. 겹친 뒤에는 가림 방법으로 구한 값과 비교하세요.
  6. 판단이 방법은 분자의 차수가 분모보다 낮을 때만 바로 쓸 수 있습니다. \(\frac{x^2}{x^2 - 1}\)처럼 차수가 같거나 높으면 먼저 나눗셈으로 \(1 + \frac{1}{x^2 - 1}\)처럼 바꾸어야 합니다. 또 분모가 \((x - 1)^2\)처럼 겹치면 \(\frac{A}{x - 1} + \frac{B}{(x - 1)^2}\) 꼴로 둡니다.

1.7.3

\(\int_0^a\sqrt{1 - x^2}\,dx\)를 원의 그림만으로 계산할 수 있을까?

삼각치환 · 조작
삼각형
—
부채꼴
—
합
—
수치 적분
—

왼쪽의 초록 넓이와 오른쪽의 초록 넓이는 같은 적분입니다. 오른쪽은 \(x = \sin\theta\)로 바꾼 뒤의 모습이고, 가로축이 \(x\) 대신 \(\theta\)입니다.

  1. 질문\(\sqrt{1 - x^2}\)의 원시함수는 표에 없고, 치환 \(u = 1 - x^2\)도 \(du = -2x\,dx\)라서 \(x\)가 남아 쓸 수 없습니다. 그런데 \(y = \sqrt{1 - x^2}\)은 단위원의 윗부분입니다. 원의 그림을 쓰면 어떨까요?
  2. 복원반지름 1, 중심각 \(\theta\)인 부채꼴의 넓이는 \(\frac{1}{2}\theta\)입니다. \(1 - \sin^2\theta = \cos^2\theta\), \(\cos^2\theta = \frac{1 + \cos 2\theta}{2}\)입니다.
  3. 설명그림으로 보면 넓이는 직각삼각형 \(\frac{1}{2}a\sqrt{1 - a^2}\)과 중심각 \(\arcsin a\)인 부채꼴 \(\frac{1}{2}\arcsin a\)의 합입니다. 계산으로는 삼각치환 \(x = \sin\theta\)를 씁니다. \(dx = \cos\theta\,d\theta\), \(\sqrt{1 - \sin^2\theta} = \cos\theta\)이므로 \(\int_0^a\sqrt{1 - x^2}\,dx = \int_0^{\arcsin a}\cos^2\theta\,d\theta = \left[\frac{\theta}{2} + \frac{\sin 2\theta}{4}\right]_0^{\arcsin a}\)이고, \(\frac{\sin 2\theta}{4} = \frac{\sin\theta\cos\theta}{2} = \frac{1}{2}a\sqrt{1 - a^2}\)이 바로 삼각형입니다. 두 방법의 답이 \(\frac{1}{2}a\sqrt{1 - a^2} + \frac{1}{2}\arcsin a\)로 같습니다.
  4. 연결\(\sqrt{a^2 - x^2}\)은 \(x = a\sin\theta\), \(\frac{1}{a^2 + x^2}\)은 \(x = a\tan\theta\)로 바꿉니다. 근호나 분모 속의 "\(a^2 \pm x^2\)"이 삼각함수의 관계식 \(1 - \sin^2\theta = \cos^2\theta\), \(1 + \tan^2\theta = \sec^2\theta\)로 한 항이 되기 때문입니다.
  5. 적용\(a\)를 0부터 1까지 움직이며 삼각형과 부채꼴이 어떻게 나눠 갖는지 보세요. \(a = 1\)이면 삼각형이 사라지고 넓이는 사분원 \(\frac{\pi}{4}\)가 됩니다. 오른쪽 그림의 넓이가 왼쪽과 늘 같은지 표로 확인하세요.
  6. 판단치환하면 적분 구간도 바꾸어야 합니다. \(x\)가 0에서 \(a\)까지 갈 때 \(\theta\)는 0에서 \(\arcsin a\)까지 갑니다. 또 \(\sqrt{\cos^2\theta} = \cos\theta\)로 쓸 수 있는 것은 이 구간에서 \(\cos\theta \ge 0\)이기 때문입니다.
