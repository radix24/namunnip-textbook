연속확률변수와 정규분포

연속확률변수의 평균은 막대의 합 대신 넓이의 무게중심, 곧 적분 \(\int x f(x)\,dx\)로 구합니다. 미적분을 배운 뒤라야 할 수 있는 계산입니다. 이 절에서는 여러 밀도함수의 평균과 표준편차를 적분으로 구하고, 이항분포를 정규분포로 어림할 때 왜 0.5를 더하고 빼는지(연속성 보정) 확인한 뒤, 직접 모은 자료에 정규곡선을 맞춰 봅니다.

먼저 알면 좋은 것 확률밀도함수와 넓이정규분포와 표준화이항분포의 평균과 표준편차정적분의 뜻과 성질

3.7.1

밀도 곡선의 어디에 받침을 대면 수평이 될까?

연속확률변수의 기댓값과 표준편차 · 조작
\(\int_0^4 f(x)dx\)
—
\(E(X) = \int x f(x)dx\)
—
\(\sigma(X)\)
—
받침 기준 돌림힘
—

—

정의역은 \(0 \le x \le 4\)입니다. "직접 만들기"에서는 곡선 위 다섯 점을 위아래로 끌 수 있고, 넓이가 1이 되도록 자동으로 맞춥니다.

  1. 질문막대 모양의 확률분포에서는 평균을 \(\sum x_i p_i\)로 구했습니다. 그런데 연속확률변수는 값이 셀 수 없이 많고 한 값의 확률은 0입니다. 평균은 어떻게 정할까요?
  2. 복원정적분은 잘게 나눈 직사각형 넓이 합의 극한입니다. 이산확률변수의 평균은 확률을 무게로 본 무게중심 \(\sum x_i p_i\)이고, 분산은 \(\sum (x_i - m)^2 p_i\)입니다.
  3. 설명구간을 잘게 나누면 \(x\) 근처의 확률은 \(f(x)\Delta x\)이므로 \(\sum x f(x)\Delta x\)의 극한, 곧 \(E(X) = \int_a^b x f(x)\,dx\)가 평균입니다. 같은 방법으로 \(V(X) = \int_a^b (x - m)^2 f(x)\,dx = \int_a^b x^2 f(x)\,dx - m^2\), \(\sigma(X) = \sqrt{V(X)}\)입니다. 밀도 곡선 아래 영역을 얇은 판으로 오려 받침 위에 올리면, 평균 자리에서 정확히 수평이 됩니다. 예를 들어 \(f(x) = \frac{x}{8}\)이면 \(E(X) = \int_0^4 \frac{x^2}{8}dx = \frac{8}{3}\)입니다.
  4. 연결이 계산은 미적분을 배운 뒤에만 할 수 있어, 확률과 통계에서는 정규분포의 평균과 표준편차를 주어진 것으로 썼습니다. 정규분포 \(\mathrm{N}(m, \sigma^2)\)의 밀도함수를 이렇게 적분하면 정말로 평균 \(m\), 표준편차 \(\sigma\)가 나옵니다.
  5. 적용받침을 움직여 돌림힘이 0이 되는(수평이 되는) 자리를 찾고, 그 자리가 \(E(X)\)와 같은지 보세요. 세 밀도함수의 평균을 직접 적분해 확인하세요. "직접 만들기"로 오른쪽이 무거운 분포를 만들면 평균은 어느 쪽으로 가나요?
  6. 판단평균은 곡선이 가장 높은 곳(최빈값)이나 넓이를 반으로 나누는 곳(중앙값)과 다를 수 있습니다. \(f(x) = \frac{x}{8}\)에서 가장 높은 곳은 4, 중앙값은 \(2\sqrt{2} \approx 2.83\), 평균은 \(\frac{8}{3} \approx 2.67\)입니다.

3.7.2

이항분포를 정규분포로 어림할 때 왜 0.5를 더하고 뺄까?

정규분포와 이항분포의 관계 · 조작
정확한 값 \(P(k_1 \le X \le k_2)\)
—
정규분포 어림(보정 없이)
—
정규분포 어림(보정)
—
  1. 질문동전을 20번 던져 앞면이 8번 이상 12번 이하로 나올 확률을 정규분포로 어림하려고 합니다. 그런데 \(P(8 \le Y \le 12)\)로 계산하면 정확한 값과 꽤 차이가 납니다. 무엇을 빠뜨린 걸까요?
  2. 복원이항분포 \(\mathrm{B}(n, p)\)의 평균은 \(np\), 분산은 \(np(1 - p)\)입니다. \(n\)이 충분히 크면 이항분포는 정규분포 \(\mathrm{N}(np, np(1 - p))\)에 가까워집니다. 정규분포의 확률은 표준화 \(Z = \frac{Y - m}{\sigma}\)로 구합니다.
  3. 설명이항분포의 막대 하나는 정수 \(k\) 하나에 서 있지만, 정규곡선으로 보면 그 막대는 \(k - 0.5\)부터 \(k + 0.5\)까지의 폭을 차지합니다. 그래서 막대 \(k_1\)부터 \(k_2\)까지를 곡선 아래 넓이로 바꾸려면 \(P(k_1 \le X \le k_2) \approx P(k_1 - 0.5 \le Y \le k_2 + 0.5)\)로 양 끝에 반 칸씩 더해야 합니다. 이것이 연속성 보정입니다. 보정하지 않으면 양 끝 막대를 반씩 잘라 버리는 셈입니다.
  4. 연결\(n\)이 아주 크면 막대 하나의 폭이 전체에 비해 작아져 보정의 효과가 줄어듭니다. 그래서 교과서의 큰 수 문제에서는 보정 없이 어림하기도 합니다. 정규 근사는 보통 \(np \ge 5\), \(n(1 - p) \ge 5\)일 때 쓸 만하다고 봅니다.
  5. 적용보정을 켜고 끄며 세 값을 비교하세요. \(k_1 = k_2\)로 두면(한 값의 확률) 보정 없는 어림은 무엇이 되나요? \(n\)을 200까지 늘리면 보정의 효과는 어떻게 되나요? \(p = 0.1\)처럼 치우치면 어림이 얼마나 나빠지나요?
  6. 판단"\(X < k\)"처럼 등호가 없는 범위는 \(X \le k - 1\)과 같으므로 보정하면 \(Y \le k - 0.5\)입니다. 부등호의 종류를 정수 범위로 먼저 바꾼 뒤 보정해야 실수를 막을 수 있습니다.

3.7.3

우리 반의 키(또는 직접 잰 자료)는 정규분포를 따를까?

정규분포 · 자료에 곡선 맞추기 · 만들기
자료 수
—
평균 \(\bar{x}\)
—
표준편차 \(s\)
—
\(\bar{x} \pm s\) 안 / \(\pm 2s\) 안
—

입력한 자료는 이 화면에서만 쓰이고 어디에도 저장되거나 보내지지 않습니다. 예시는 컴퓨터가 만든 모의 자료로, 실제 측정값이 아닙니다.

  1. 질문여러 사람의 키를 모아 히스토그램을 그리면 가운데가 볼록한 종 모양이 나온다고 합니다. 직접 모은 자료도 정말 그럴까요? 종 모양이라는 것은 무엇으로 확인할 수 있을까요?
  2. 복원정규분포 \(\mathrm{N}(m, \sigma^2)\)에서 \(P(m - \sigma \le X \le m + \sigma) \approx 0.683\), \(P(m - 2\sigma \le X \le m + 2\sigma) \approx 0.954\)입니다.
  3. 설명자료의 평균 \(\bar{x}\)와 표준편차 \(s\)를 구해 \(\mathrm{N}(\bar{x}, s^2)\)의 곡선을 히스토그램 위에 겹쳐 봅니다. 히스토그램은 높이를 "상대도수 ÷ 칸 폭"으로 그려야 곡선과 같은 눈금이 됩니다. 정규분포에 가까운 자료라면 막대가 곡선을 따라가고, \(\bar{x} \pm s\) 안에 약 68 %, \(\bar{x} \pm 2s\) 안에 약 95 %가 들어갑니다. 여러 요인이 조금씩 더해져 생기는 양(키, 측정 오차)은 정규분포에 가까운 경우가 많습니다.
  4. 연결정규분포가 이렇게 자주 나타나는 까닭은 "독립인 작은 효과를 많이 더하면 그 합은 정규분포에 가까워진다"는 중심극한정리입니다. 갈톤 보드에서 공이 종 모양으로 쌓인 것도 같은 원리입니다.
  5. 적용친구들의 키, 한 달 동안의 등교 시간, 같은 물건을 여러 번 잰 길이처럼 직접 모은 자료를 넣어 보세요. 68 %, 95 % 규칙에 얼마나 가깝나요? 칸 수를 바꾸면 모양이 어떻게 달라 보이나요? 자료가 20개 이하일 때와 100개 이상일 때를 비교해 보세요.
  6. 판단모든 자료가 정규분포를 따르지는 않습니다. 소득, 대기 시간, 시험 점수처럼 한쪽으로 꼬리가 길거나 봉우리가 둘인 자료도 흔합니다. 남녀를 섞은 키처럼 서로 다른 집단이 섞이면 봉우리가 둘로 보일 수 있습니다. 곡선을 겹쳐 보고 확인한 뒤에 정규분포를 써야 합니다.
