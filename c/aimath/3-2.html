행렬 연산과 이미지 변환

이미지가 행렬이면 이미지를 바꾸는 일은 행렬을 계산하는 일입니다. 모든 성분에 같은 수를 더하면 밝아지고, 전치하면 대각선으로 뒤집힙니다. 주변 픽셀과 함께 계산하는 합성곱을 쓰면 흐리게 하거나 윤곽을 찾을 수 있습니다. 이 절에서는 이런 계산을 직접 적용해 봅니다.

3.2.1

사진 편집 앱의 버튼은 행렬에 어떤 계산을 할까?

행렬 연산과 이미지 변환 · 조작

원래 A

원과 네모, 줄로 만든 24×24 가상 이미지입니다. 계산 결과가 0보다 작으면 0, 255보다 크면 255로 자릅니다.

  1. 질문사진 편집 앱에서 "밝게", "대비", "뒤집기"를 누르면 사진이 바로 바뀝니다. 앱은 사진의 행렬에 어떤 계산을 하는 걸까요?
  2. 복원행렬의 실수배 \(kA\), 행렬의 덧셈과 뺄셈, 행렬의 곱셈.
  3. 설명밝기는 모든 성분에 같은 수를 더하는 것(\(A + kJ\), \(J\)는 성분이 모두 1인 행렬), 대비는 128을 기준으로 차이를 늘리는 것(\(c(A - 128J) + 128J\)), 반전은 \(255J - A\)입니다. 이미지를 대각선으로 뒤집으면 \((i, j)\) 성분과 \((j, i)\) 성분이 바뀐 행렬이 되는데, 이를 전치행렬 \(A^T\)라 합니다. 좌우로 뒤집으려면 오른쪽에 반대각선이 1인 행렬 \(R\)을 곱합니다(\(AR\)). 이처럼 이미지 처리는 대부분 행렬 연산입니다.
  4. 연결인공지능에 사진을 학습시킬 때 같은 사진을 뒤집거나 밝기를 바꿔 자료를 늘리기도 합니다(데이터 증강). 다음 카드는 주변 픽셀을 함께 쓰는 계산(합성곱)입니다.
  5. 적용각 변환을 해 보며 성분이 어떻게 바뀌는지 설명하세요. 반전을 두 번 하면 어떻게 되나요? 전치를 두 번 하면요?
  6. 판단255를 넘거나 0보다 작아진 값은 잘려서 원래 정보가 사라집니다. 너무 밝게 한 뒤 다시 어둡게 해도 원래 사진으로 돌아오지 않습니다.

  3. 설명3×3 행렬 \(K\)(필터)를 이미지 위에 올려, 겹치는 9개 성분끼리 곱해 더한 값을 가운데 픽셀의 새 값으로 합니다. 이것을 모든 픽셀에서 반복하는 계산을 합성곱이라 합니다. 9칸이 모두 \(\frac19\)이면 평균이라 흐려지고, 위쪽 행은 음수, 아래쪽 행은 양수(예: \(-1, -2, -1\)과 \(1, 2, 1\))이면 위아래 밝기 차이가 큰 곳, 곧 가로 윤곽에서 값이 커집니다.
    4. 
            
  4. 연결이미지를 다루는 인공지능(합성곱 신경망)은 필터의 9개 수를 사람이 정하지 않고 자료로 학습합니다. 처음 층은 윤곽을, 다음 층은 모양을, 더 깊은 층은 물체를 알아보는 필터가 학습됩니다.
    5. 
            
  5. 적용필터를 바꿔 결과를 비교하고, 원래 이미지를 눌러 한 픽셀의 계산을 따라가 보세요. 필터 성분을 직접 바꿔 대각선 윤곽을 찾는 필터를 만들어 보세요.
