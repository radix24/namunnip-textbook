포함배제의 원리

여러 집합의 합집합 원소 수를 셀 때는 겹친 부분을 여러 번 세지 않도록 더하고 빼기를 번갈아 합니다. 이것이 포함배제의 원리입니다. 이 절에서는 세 집합의 벤 다이어그램에서 각 영역이 정확히 한 번씩 세어지는 과정을 따라가고, 아무도 자기 모자를 받지 못하는 경우의 수를 이 원리로 구해 실험과 비교합니다.

1.3.1

세 집합을 합칠 때 왜 더하고 빼고 다시 더할까?

포함배제의 원리 · 조작

영역을 누르면 그 영역의 원소가 하나 늘어납니다. 빨간 배지는 그 영역을 지금까지 몇 번 셌는지입니다.

  1. 질문설문에서 축구를 좋아하는 학생 A명, 농구 B명, 야구 C명이라고 합니다. 셋 중 하나라도 좋아하는 학생은 \(A + B + C\)명일까요?
  2. 복원두 집합에서 \(n(A \cup B) = n(A) + n(B) - n(A \cap B)\)입니다. 겹친 부분을 두 번 셌으니 한 번 뺍니다.
  3. 설명세 집합이면 ① 세 집합을 더할 때 두 집합에만 속한 원소는 2번, 세 집합 모두에 속한 원소는 3번 셉니다. ② 두 개씩의 교집합 세 개를 빼면 두 집합에만 속한 원소는 1번이 되지만, 세 집합 모두에 속한 원소는 \(3 - 3 = 0\)번이 됩니다. ③ 그래서 세 집합의 교집합을 다시 더합니다. \(n(A \cup B \cup C) = \sum n(A) - \sum n(A \cap B) + n(A \cap B \cap C)\). 이것이 포함배제의 원리이며, 집합이 더 많아도 "홀수 개의 교집합은 더하고 짝수 개는 뺀다"로 이어집니다.
  4. 연결"어느 것도 아닌 것"을 세려면 전체에서 합집합을 뺍니다. 다음 카드의 교란순열, 앞 절의 "4 이하" 정수해, 1부터 100까지 2, 3, 5 중 어느 것으로도 나누어지지 않는 수 세기가 모두 이 방법입니다.
  5. 적용①, ②, ③을 차례로 누르며 각 영역의 배지가 어떻게 바뀌는지 보세요. ③ 뒤에는 모든 영역이 1이 되나요? 영역의 수를 바꿔도 같은가요?
  6. 판단문제에서 "A와 B를 좋아하는 학생"이 "A와 B만 좋아하는 학생"인지 "A와 B를 둘 다 좋아하는 학생(C도 포함)"인지 구별해야 합니다. 공식의 \(n(A \cap B)\)는 C도 좋아하는 학생을 포함합니다.

1.3.2

모자를 섞어 돌려주면 아무도 제 것을 못 받을 확률은?

교란순열 · 시뮬레이션

  1. 질문파티에 온 \(n\)명이 맡긴 모자를 무작위로 돌려받습니다. 아무도 자기 모자를 받지 못할 확률은 사람이 많아질수록 어떻게 될까요? 1에 가까워질까요, 0에 가까워질까요?
  2. 복원포함배제의 원리: "적어도 하나"는 홀수 개의 교집합을 더하고 짝수 개를 뺍니다.
  3. 설명\(A_i\)를 "\(i\)번째 사람이 제 모자를 받는" 배열의 집합이라 하면, \(k\)명을 정해 제 모자를 받게 하는 배열은 \((n - k)!\)가지이고 그런 \(k\)명을 고르는 방법은 \({}_n\mathrm{C}_k\)입니다. 따라서 아무도 제 것을 받지 않는 배열(교란순열)의 수는 \(D_n = n!\left(1 - \frac{1}{1!} + \frac{1}{2!} - \cdots + \frac{(-1)^n}{n!}\right)\)입니다. 확률 \(D_n/n!\)은 \(n\)이 커지면 \(\frac{1}{e} \approx 0.3679\)로 빠르게 다가갑니다.
  4. 연결교란순열은 점화식 \(D_n = (n - 1)(D_{n-1} + D_{n-2})\)도 만족합니다(다음 단원의 점화 관계). 비밀 산타 뽑기에서 자기 이름을 뽑지 않을 확률이 바로 이 값입니다.
  5. 적용먼저 \(n = 6\)일 때 확률을 짐작해 보세요. 1000번 섞기를 여러 번 눌러 비율이 어디로 모이는지 보세요. \(n\)을 2, 3, 12로 바꾸면 어떻게 되나요?
  6. 판단사람이 많을수록 "누군가는 자기 것을 받겠지" 싶어 확률이 0으로 갈 것 같지만, 실제로는 약 37%에 머뭅니다. 직관과 다른 결과는 계산과 실험으로 확인해야 합니다. 시행 횟수가 적으면 비율이 크게 흔들린다는 점도 기억하세요.
