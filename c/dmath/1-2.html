1.2.1

같은 사탕을 친구들에게 나누는 방법은 몇 가지일까?

중복조합 · 조작

아래 칸을 누르면 사탕(★)과 칸막이(|)가 서로 바뀝니다. 칸막이는 늘 n − 1개입니다.

—

  1. 질문똑같은 사탕 5개를 세 친구에게 나눠 줍니다. 못 받는 친구가 있어도 됩니다. (5, 0, 0), (2, 2, 1), … 하나씩 적다 보면 빠뜨리기 쉽습니다. 한 번에 세는 방법이 있을까요?
  2. 복원같은 것이 있는 순열: ★ 5개와 | 2개를 늘어놓는 방법은 \(\frac{7!}{5!\,2!}\)가지입니다.
  3. 설명사탕을 ★, 친구 사이의 경계를 |로 그리면 ★★|★★|★은 (2, 2, 1)입니다. 나눔 하나가 ★ \(r\)개와 | \(n - 1\)개의 줄 하나에 꼭 맞게 대응하므로, 나누는 방법의 수는 \(r + n - 1\)칸 중 | 자리를 고르는 수 \({}_{r+n-1}\mathrm{C}_{n-1} = {}_{r+n-1}\mathrm{C}_r\)입니다. 이것을 서로 다른 \(n\)개에서 중복을 허락해 \(r\)개를 고르는 중복조합 \({}_n\mathrm{H}_r\)이라고 합니다.
  4. 연결\({}_n\mathrm{H}_r\)은 방정식 \(x_1 + \cdots + x_n = r\)의 음이 아닌 정수해의 개수이기도 합니다(다음 카드). 아이스크림 맛 고르기, 다항식 \((x + y + z)^r\)의 항의 개수도 같은 수입니다.
  5. 적용칸을 눌러 여러 나눔을 만들고 기록하세요. 중복 없이 모두 모으면 몇 개인가요? 식으로 구한 \({}_n\mathrm{H}_r\)과 같은가요?
  6. 판단"모든 친구가 적어도 하나씩 받는다"면 먼저 한 개씩 나눠 준 뒤 남은 \(r - n\)개를 나누므로 \({}_n\mathrm{H}_{r-n}\)입니다. 사탕이 서로 다르면 친구 선택을 사탕마다 하므로 \(n^r\)(중복순열)입니다. 무엇이 같고 무엇이 다른지 먼저 확인하세요.

조건이 붙은 방정식의 정수해는 몇 개일까?

중복조합과 정수해 · 예측→확인

예측: 해의 개수는?

  1. 질문방정식 \(x + y + z = 8\)의 음이 아닌 정수해는 중복조합으로 셀 수 있었습니다. 그런데 "모두 1 이상", "\(x \ge 3\)", "모두 4 이하" 같은 조건이 붙으면 어떻게 셀까요?
  2. 복원\(x_1 + \cdots + x_n = r\)의 음이 아닌 정수해의 개수는 \({}_n\mathrm{H}_r = {}_{n+r-1}\mathrm{C}_r\)입니다.
  3. 설명아래로 막힌 조건은 미리 나눠 주고 셉니다. \(x \ge 3\)이면 \(x = x' + 3\)으로 두어 \(x' + y + z = 5\), 곧 \({}_3\mathrm{H}_5 = 21\)개입니다. "모두 1 이상"은 하나씩 먼저 주고 \({}_3\mathrm{H}_5\)입니다. 위로 막힌 조건 "4 이하"는 이렇게 바꿀 수 없어서, 전체에서 "어느 하나가 5 이상"인 해를 빼야 하며 이때 겹치는 것을 조심해야 합니다(다음 절의 포함배제의 원리).
  4. 연결세 변수의 해는 정삼각형 모양 격자의 점으로 그릴 수 있습니다. 꼭짓점이 \((8, 0, 0)\), \((0, 8, 0)\), \((0, 0, 8)\)이고, 아래로 막힌 조건은 작은 삼각형을, 위로 막힌 조건은 모서리를 잘라 낸 육각형을 남깁니다.
  5. 적용네 문제의 답을 먼저 예측한 뒤 그림으로 확인하세요. 문제 4에서 잘려 나간 세 모서리 삼각형은 각각 몇 개의 점을 가지나요? 서로 겹치나요?
  6. 판단"양의 정수해"와 "음이 아닌 정수해"는 다릅니다. 문제를 읽을 때 0을 허용하는지 먼저 확인해야 합니다.
