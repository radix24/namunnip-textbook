인접행렬

그래프를 컴퓨터에 넣으려면 그림이 아니라 수의 표로 바꿔야 합니다. 이어진 두 꼭짓점의 자리에 1, 아니면 0을 적은 행렬이 인접행렬입니다. 행렬로 바꾸면 행렬의 계산으로 그래프의 성질을 알아낼 수 있습니다. 이 절에서는 그래프와 인접행렬을 오가며 바꿔 보고, 인접행렬의 거듭제곱이 경로의 수를 세어 주는 것을 확인합니다.

4.3.1

그래프를 수의 표로 바꾸면 무엇을 계산할 수 있을까?

인접행렬 · 조작

  1. 질문컴퓨터는 그림을 볼 수 없습니다. 꼭짓점이 수천 개인 연결망을 컴퓨터에 넣으려면 그래프를 어떤 모양의 자료로 바꿔야 할까요?
  2. 복원행렬의 \((i, j)\) 성분은 \(i\)행 \(j\)열의 수입니다.
  3. 설명꼭짓점이 \(n\)개인 그래프에서 \(i\)와 \(j\)가 변으로 이어져 있으면 1, 아니면 0을 \((i, j)\) 성분으로 하는 \(n \times n\) 행렬을 인접행렬이라 합니다. 방향 없는 그래프의 인접행렬은 대각선에 대해 대칭이고, 대각성분은 0(고리 없음)이며, \(i\)행의 합이 꼭짓점 \(i\)의 차수입니다. 방향그래프에서는 \(i \to j\)일 때만 \((i, j)\) 성분이 1이라 대칭이 아닐 수 있고, 행의 합은 나가는 변, 열의 합은 들어오는 변의 수입니다.
  4. 연결인접행렬을 거듭제곱하면 경로의 수를 셀 수 있습니다(다음 카드). 고급 대수의 페이지랭크도 방향그래프의 인접행렬에서 시작했습니다.
  5. 적용그래프에서 변을 잇고 행렬이 어떻게 바뀌는지, 행렬의 칸을 눌러 그래프가 어떻게 바뀌는지 보세요. "방향 있음"으로 바꾸면 행렬의 대칭이 어떻게 되나요? 행의 합과 차수를 비교하세요.
  6. 판단꼭짓점의 번호를 바꾸면 인접행렬의 모양은 달라지지만 그래프는 같습니다. 그래서 두 행렬이 다르게 생겼다고 두 그래프가 다르다고 단정할 수 없습니다.

4.3.2

세 번 갈아타서 도착하는 항공편 경로는 몇 가지일까?

인접행렬의 거듭제곱 · 활용

  1. 질문다섯 도시 사이에 직항 노선이 있습니다. 서울에서 출발해 비행기를 정확히 세 번 타고 부산에 도착하는 경로(같은 도시를 다시 들러도 됨)는 몇 가지일까요? 하나하나 세지 않고 계산할 수 있을까요?
  2. 복원인접행렬 \(A\)의 \((i, j)\) 성분은 \(i\)와 \(j\) 사이의 변의 수입니다. 행렬의 곱 \(AB\)의 \((i, j)\) 성분은 \(A\)의 \(i\)행과 \(B\)의 \(j\)열에서 같은 순서의 성분끼리 곱해 더한 값입니다.
  3. 설명\((A^2)_{ij} = A_{i1}A_{1j} + A_{i2}A_{2j} + \cdots + A_{in}A_{nj}\)는 "\(i\)에서 \(m\)으로, \(m\)에서 \(j\)로" 가는 길을 중간 도시 \(m\)마다 세어 더한 것이므로 길이 2인 경로의 수입니다. 같은 이유로 \((A^k)_{ij}\)는 \(i\)에서 \(j\)로 가는 길이 \(k\)인 경로(같은 꼭짓점을 다시 지나도 됨)의 수입니다. 대각성분 \((A^2)_{ii}\)는 꼭짓점 \(i\)의 차수와 같습니다.
  4. 연결\((A^3)_{ii}\)의 합을 6으로 나누면 그래프 속 삼각형의 개수가 됩니다. 사회 연결망 분석에서 "친구의 친구의 친구" 수를 세거나, 고급 대수의 마르코프 연쇄에서 여러 단계 뒤의 확률을 계산할 때 같은 원리를 씁니다.
  5. 적용출발, 도착, \(k\)를 바꾸며 표의 강조된 수와 아래 경로 목록의 개수가 같은지 확인하세요. \(k = 2\)에서 대각선의 수는 각 도시의 노선 수와 같나요?
  6. 판단\((A^k)_{ij}\)는 같은 도시를 여러 번 지나는 경로까지 셉니다. 한 도시를 한 번만 지나는 경로(단순 경로)의 수는 이렇게 쉽게 구할 수 없습니다. 노선은 수업용으로 만든 가상의 것입니다.
