점화 관계와 일반항

점화 관계만으로도 수열의 모든 항을 차례로 구할 수 있지만, 일반항을 알면 먼 항과 극한을 바로 알 수 있습니다. \(a_{n+1} = pa_n + q\)는 고정된 값 하나를 빼면 등비수열이 됩니다. 이 절에서는 거미줄 그림으로 수열이 모이는지 흩어지는지 미리 보고, 대출 상환이라는 실제 문제를 점화식으로 풀어 봅니다.

2.2.1

점화식만 보고 수열이 어디로 갈지 알 수 있을까?

점화 관계와 일반항 · 조작

  1. 질문\(a_{n+1} = 0.5a_n + 2\)이면 수열은 커질까요, 작아질까요, 어느 값에 머물까요? 항을 하나하나 계산하지 않고 알 수 있을까요?
  2. 복원한 단계마다 같은 수 \(p\)를 곱하는 수열 \(b_{n+1} = pb_n\)(대수의 등비수열)의 일반항은 \(b_n = b_1p^{n-1}\)이고, \(|p| < 1\)이면 \(b_n\)은 0에 한없이 가까워집니다.
  3. 설명\(\alpha = p\alpha + q\)인 수 \(\alpha = \dfrac{q}{1 - p}\) (\(p \ne 1\))를 찾아 빼면 \(a_{n+1} - \alpha = p(a_n - \alpha)\)가 되어 등비수열이 나옵니다. 그래서 일반항은 \(a_n = \alpha + (a_1 - \alpha)p^{n-1}\)이고, \(|p| < 1\)이면 \(\alpha\)에 한없이 가까워지고, \(|p| > 1\)이면 \(\alpha\)에서 멀어지며, \(p < 0\)이면 \(\alpha\)의 양쪽을 번갈아 오갑니다. 거미줄 그림에서 \(\alpha\)는 두 직선 \(y = px + q\)와 \(y = x\)의 교점입니다. 이웃한 세 항의 관계 \(a_{n+2} = ra_{n+1} + sa_n\)은 특성방정식 \(t^2 = rt + s\)의 근으로 풉니다.
  4. 연결약을 일정한 간격으로 먹을 때 몸속 약의 양(매번 일정 비율이 빠져나가고 일정량이 들어옴), 다음 카드의 대출 잔액이 모두 이 꼴의 점화식입니다.
  5. 적용\(p\)를 0.5, −0.5, 1.2, −1.2로 바꾸며 거미줄이 교점으로 모이는지, 계단 모양인지, 소용돌이인지 보세요. \(a_1 = \alpha\)로 맞추면 어떻게 되나요?
  6. 판단\(p = 1\)이면 \(\alpha\)가 없고 수열은 공차 \(q\)인 등차수열입니다. 공식 \(\frac{q}{1 - p}\)에 그대로 넣으면 0으로 나누게 됩니다. 공식이 성립하는 조건을 먼저 확인하세요.

확인조건이 달라지면

\(a_1 = 1\), \(a_{n+1} = \frac{1}{3}a_n + 4\)인 수열의 극한값은?

2.2.2

매달 얼마씩 갚아야 24개월 만에 대출이 끝날까?

점화 관계의 활용 · 도전

수치는 수업용으로 정한 모의 값입니다. 실제 대출은 이자 계산 방식과 수수료가 상품마다 다릅니다.

  1. 질문1000만 원을 월 0.5% 이자로 빌려 매달 같은 금액을 갚습니다. 24개월 만에 다 갚으려면 매달 얼마씩 내야 할까요? 이자 없이 나누면 약 41.7만 원인데, 이자가 붙으면 얼마나 더 필요할까요?
  2. 복원\(a_{n+1} = pa_n + q\)는 \(\alpha = \frac{q}{1 - p}\)를 빼서 등비수열로 바꿉니다. 등비수열의 합(대수) \(1 + p + \cdots + p^{k-1} = \frac{p^k - 1}{p - 1}\)은 합에 \(p\)를 곱한 식에서 원래 합을 빼서 얻습니다.
  3. 설명\(n\)개월 뒤 남은 빚을 \(b_n\)이라 하면 한 달 동안 이자가 붙고 \(M\)을 갚으므로 \(b_{n+1} = (1 + r)b_n - M\)입니다. 일반항은 \(b_n = (1 + r)^nB - M\dfrac{(1 + r)^n - 1}{r}\)이고, \(b_N = 0\)으로 놓으면 매달 갚을 돈은 \(M = \dfrac{Br(1 + r)^N}{(1 + r)^N - 1}\)입니다(원리금 균등 상환).
  4. 연결적금(매달 넣고 이자가 붙음)은 \(a_{n+1} = (1 + r)a_n + M\)으로 부호만 다릅니다. 연금, 할부 구매도 같은 점화식으로 계산합니다.
  5. 적용"매달 갚는 돈"을 조절해 24개월째에 빚이 정확히 0 근처가 되게 맞추세요. 그다음 공식으로 확인하세요. 이자율을 두 배로 하면 매달 갚는 돈은 얼마나 늘어나나요? 갚는 돈이 첫 달 이자보다 적으면 그래프가 어떻게 되나요?
  6. 판단매달 갚는 돈이 이자 \(rB\)보다 작으면 빚이 오히려 늘어납니다(\(p = 1 + r > 1\)이라 \(\alpha\)에서 멀어짐). 총 이자는 "갚은 돈의 합 \(-\) 빌린 돈"이므로 기간이 길수록 매달 부담은 줄어도 총 이자는 커집니다.

확인조건이 달라지면

\(b_{n+1} = 1.01b_n - 20\), \(b_0 = 1000\)일 때 빚이 줄어들지도 늘어나지도 않으려면 매달 얼마를 갚아야 할까요?
