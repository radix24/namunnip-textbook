3.3.1

자동차 수요가 100억 원 늘면 철강은 얼마나 더 만들어야 할까?

산업 연관 분석 · 조작

가상의 두 산업: 철강 1원어치를 만들려면 철강 0.2원과 자동차 0.1원어치가 들고, 자동차 1원어치를 만들려면 철강 0.4원과 자동차 0.1원어치가 듭니다.

투입 계수는 수업용 가상 값입니다. 실제 산업연관표는 한국은행이 수십~수백 개 산업으로 작성합니다.

  1. 질문사람들이 자동차를 100억 원어치 더 산다면 자동차 공장만 100억 원어치 더 만들면 될까요? 자동차를 만드는 데 드는 철강, 그 철강을 만드는 데 드는 또 다른 재료는 어떻게 될까요?
  2. 복원\(AX = B\)이고 \(A^{-1}\)이 있으면 \(X = A^{-1}B\)입니다. 단위행렬 \(I\)는 \(IX = X\)를 만족합니다.
  3. 설명산업 \(j\)가 1원어치를 만들 때 필요한 산업 \(i\)의 생산물을 투입 계수 \(a_{ij}\)라 하고, 이를 모은 행렬을 \(A\)라 합니다. 각 산업의 총생산 \(X\)는 다른 산업에 재료로 쓰이는 양 \(AX\)와 소비자가 쓰는 최종 수요 \(D\)의 합이므로 \(X = AX + D\), 곧 \((I - A)X = D\)이고 \(X = (I - A)^{-1}D\)입니다. \((I - A)^{-1}\)의 성분은 최종 수요 1원이 늘 때 각 산업의 생산이 얼마나 늘어야 하는지(생산 유발 계수)를 알려 줍니다.
  4. 연결이 방법을 만든 레온티예프는 1973년 노벨 경제학상을 받았습니다. 정부는 산업연관표로 새 정책이나 투자가 경제 전체에 미치는 효과를 계산합니다.
  5. 적용자동차 최종 수요만 100억 원 늘려 보세요. 철강 생산은 얼마나 늘어나나요? 자동차 생산은 왜 100억 원보다 더 늘어나야 하나요?
  6. 판단최종 수요만큼만 생산하면 재료가 모자랍니다. 산업끼리 서로 재료를 주고받으므로 효과는 사슬처럼 이어집니다(\(D + AD + A^2D + \cdots\)).

3.3.2

돼지고기 값이 오르면 닭고기 값은 왜 따라 오를까?

연립 시장 균형 · 활용

가상의 두 시장(가격 \(P_1, P_2\)는 100 g당 백 원, 수량은 톤). 돼지고기와 닭고기는 서로 대신 먹을 수 있어서, 한쪽 값이 오르면 다른 쪽 수요가 늡니다.

  • 돼지고기: 수요 \(Q = 120 + s - 3P_1 + P_2\), 공급 \(Q = 2P_1 - 10\)
  • 닭고기: 수요 \(Q = 105 + P_1 - 4P_2\), 공급 \(Q = 3P_2 - 5\)

함수와 수치는 수업용 가상 값입니다.

  1. 질문돼지 전염병으로 돼지고기 공급이 줄거나, 돼지고기가 인기를 끌면 닭고기 값까지 오르는 일이 있습니다. 두 시장을 함께 다루려면 어떻게 해야 할까요?
  2. 복원균형에서는 수요량과 공급량이 같습니다(2단원). 연립일차방정식 \(AX = B\)는 \(X = A^{-1}B\)로 풉니다.
  3. 설명각 시장의 균형 조건 \(Q_d = Q_s\)를 정리하면 \(5P_1 - P_2 = 130 + s\), \(-P_1 + 7P_2 = 110\)입니다. 행렬로 쓰면 \(\begin{pmatrix} 5 & -1 \\ -1 & 7 \end{pmatrix}\begin{pmatrix} P_1 \\ P_2 \end{pmatrix} = \begin{pmatrix} 130 + s \\ 110 \end{pmatrix}\)이고, 역행렬을 곱하면 두 균형 가격이 한꺼번에 나옵니다. \(s = 0\)일 때 \(P_1 = 30\), \(P_2 = 20\)입니다. 그림에서 두 직선은 각 시장이 균형인 가격 조합이고, 교점에서 두 시장이 함께 균형입니다.
  4. 연결대체재(돼지고기와 닭고기)와 보완재(자동차와 휘발유)처럼 연결된 시장은 따로 분석하면 효과를 놓칩니다. 경제 전체를 이런 연립방정식으로 다루는 것을 일반 균형 분석이라 합니다.
  5. 적용\(s\)를 늘려 돼지고기 수요가 늘 때 두 가격이 각각 얼마나 오르는지 보세요. 역행렬의 어느 성분이 닭고기 값의 변화를 알려 주나요?
  6. 판단한 시장만 보면 닭고기 시장에는 아무 변화가 없는 것처럼 보입니다. 연결된 시장에서는 한 가격의 변화가 다른 시장의 수요를 바꾸고, 그것이 다시 처음 시장에 돌아옵니다.
