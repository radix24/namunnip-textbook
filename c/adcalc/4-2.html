오일러의 방법

방향장을 따라 "조금 가고, 기울기를 다시 보고, 또 조금 간다"를 계산으로 하는 것이 오일러의 방법입니다. 식으로 풀 수 없는 미분방정식도 이 방법으로 근사해를 얻을 수 있습니다. 이 절에서는 걸음 크기를 줄여 가며 오차가 어떻게 줄어드는지 확인하고, 오차가 한쪽으로 쌓이면 원을 그려야 할 공이 나선을 그리며 달아나는 것을 시뮬레이션으로 봅니다.

4.2.1

접선을 따라 한 걸음씩 가면 해를 얼마나 정확히 그릴 수 있을까?

오일러의 방법 · 조작 · 발견
오일러 \(y_n\)
—
참값
—
오차 × \(n\)
—

구간은 \(0 \le x \le 2\)입니다(첫 보기만 \(0 \le x \le 1\)). 걸음 수 막대는 1, 2, 4, …, 128처럼 두 배씩 늘어납니다.

  1. 질문방향장을 따라 해 곡선을 손으로 그릴 때 우리는 "조금 가고, 기울기를 다시 보고, 또 조금 간다"를 되풀이합니다. 이것을 계산으로 정확히 하면 해의 근삿값을 얻을 수 있을까요? 걸음을 줄이면 얼마나 정확해질까요?
  2. 복원점 \((x_n, y_n)\)에서의 접선은 \(y = y_n + f(x_n, y_n)(x - x_n)\)입니다. \(\left(1 + \frac{1}{n}\right)^n \to e\)입니다.
  3. 설명오일러의 방법은 걸음 크기 \(h\)를 정하고 \[y_{n+1} = y_n + h\,f(x_n, y_n)\]을 \(x_{n+1} = x_n + h\)와 함께 되풀이합니다. 한 걸음마다 접선을 따라가므로 곡선이 휜 만큼 오차가 생기고, 그 오차가 쌓입니다. 끝점의 오차는 대략 \(h\)에 비례합니다. 그래서 걸음 수를 두 배로 하면 오차가 대략 절반이 되고, "오차 × \(n\)"이 거의 일정해집니다. \(y' = y\)에 \(h = \frac{1}{n}\)로 쓰면 \(y_n = \left(1 + \frac{1}{n}\right)^n\)이 되어 \(e\)의 정의와 만납니다.
  4. 연결오차가 \(h\)에 비례하는 방법을 1차 방법이라고 합니다. 정확도를 한 자리 높이려면 계산을 10배 해야 하므로 실제로는 잘 쓰이지 않고, 기울기를 여러 번 재어 평균하는 룽게–쿠타 방법(오차가 \(h^4\)에 비례) 같은 방법을 씁니다. 이 단원의 그림 속 해 곡선도 룽게–쿠타 방법으로 그렸습니다.
  5. 적용걸음 수를 1, 2, 4, …로 늘리며 꺾은선이 참값 곡선에 다가가는 것을 보세요. 아래 표에서 걸음 수가 두 배가 될 때 오차가 대략 절반이 되나요? \(y' = y\)에서 꺾은선은 왜 언제나 곡선 아래에 있나요?
  6. 판단오일러의 방법은 위로 볼록한 곳에서는 위로, 아래로 볼록한 곳에서는 아래로 치우치는 계통 오차를 냅니다. 걸음을 줄이면 오차는 줄지만, 걸음이 너무 많으면 컴퓨터의 반올림 오차가 쌓이기 시작합니다. 다음 카드에서는 오차가 쌓여 결과가 완전히 틀어지는 경우를 봅니다.

4.2.2

원을 그려야 할 공이 왜 점점 멀어질까?

오일러의 방법의 오차 · 시뮬레이션 · 판단
세 바퀴 뒤 반지름 (오일러)
—
\((1 + h^2)^{N/2}\)
—
세 바퀴 뒤 반지름 (고친 것)
—

\(N\)은 세 바퀴(\(t = 6\pi\))에 필요한 걸음 수입니다. 고친 오일러는 \(x\)를 먼저 새로 구하고 그 새 \(x\)로 \(y\)를 구하는 방법입니다.

  1. 질문원 위를 도는 공의 속도는 언제나 원의 접선 방향입니다. 이 운동을 오일러의 방법으로 계산하면, 공은 계속 원 위에 머물까요?
  2. 복원오일러의 방법: \(y_{n+1} = y_n + h\,y'_n\). 반지름 1인 원 위를 각속도 1로 도는 점은 \(x' = -y\), \(y' = x\)를 만족하고, 해는 \((\cos t, \sin t)\)입니다.
  3. 설명오일러의 방법은 지금 점의 접선 방향으로 \(h\)만큼 똑바로 나아갑니다. 원의 접선은 원 바깥으로 나가므로, 한 걸음마다 반지름이 \(\sqrt{1 + h^2}\)배가 됩니다. 실제로 \(x_{n+1}^2 + y_{n+1}^2 = (x_n - hy_n)^2 + (y_n + hx_n)^2 = (1 + h^2)(x_n^2 + y_n^2)\)입니다. 걸음 하나의 오차는 작아도 같은 방향(바깥쪽)으로 쌓이므로 궤도가 나선으로 풀려 나갑니다. 순서만 살짝 바꾼 고친 오일러 방법(\(x\)를 먼저 새로 구하고 새 \(x\)로 \(y\)를 구함)은 오차가 쌓이지 않고 원 근처에 머뭅니다.
  4. 연결게임의 물리 엔진이나 행성 궤도 계산에서 단순한 오일러 방법을 쓰면 에너지가 저절로 늘어나 물체가 점점 빨라지거나 궤도에서 벗어납니다. 그래서 이런 계산에는 고친 오일러 방법(반암시적 오일러), 베를레 방법처럼 에너지를 잘 보존하는 방법을 씁니다.
  5. 적용\(h\)를 바꾸며 세 바퀴 뒤 반지름을 보세요. 계산값이 \((1 + h^2)^{N/2}\)과 같나요? \(h\)를 줄이면 오일러의 결과가 1에 가까워지나요? 고친 오일러는 \(h = 0.5\)에서도 원 근처에 머무나요?
  6. 판단한 걸음의 오차만 보고 방법을 고르면 안 됩니다. 두 방법은 한 걸음의 오차 크기가 같은 정도이지만, 오차가 쌓이는 방식이 달라 오랜 시간 뒤의 결과가 크게 다릅니다. 수치 계산에서는 무엇이 보존되어야 하는지(여기서는 반지름, 곧 에너지)를 함께 따져야 합니다.
