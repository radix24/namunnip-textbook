테일러급수의 활용

테일러급수는 계산기 속의 계산, 물리 법칙의 근사, 오차의 크기를 어림하는 데 쓰입니다. 이 절에서는 계산기가 \(\sin 1000^\circ\)를 구하는 과정을 따라가 보고, 진자의 주기 공식이 \(\sin\theta \approx \theta\)라는 근사에서 나왔다는 것과 그 한계를 시뮬레이션으로 확인하고, 상대성 이론의 운동 에너지를 급수로 펼쳐 뉴턴의 \(\frac{1}{2}mv^2\)이 나오는 것을 봅니다.

3.7.1

계산기는 \(\sin 1000^\circ\)를 어떻게 계산할까?

테일러급수의 활용 · 활용
참값
—
옮겨서 계산한 오차
—
옮기지 않은 오차
—
  1. 질문\(\sin x = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \cdots\)은 모든 \(x\)에서 성립합니다. 그러면 \(\sin 1000^\circ\)도 \(x = \frac{1000\pi}{180} \approx 17.45\)를 넣어 몇 항만 더하면 될까요?
  2. 복원\(\sin(\theta + 360^\circ) = \sin\theta\), \(\sin(180^\circ + \theta) = -\sin\theta\), \(\sin(180^\circ - \theta) = \sin\theta\), \(\sin(90^\circ - \theta) = \cos\theta\). 테일러다항식의 오차는 대략 빠진 첫 항 \(\frac{|x|^{n+1}}{(n + 1)!}\) 크기입니다.
  3. 설명\(x = 17.45\)이면 \(\frac{x^{n}}{n!}\)이 \(n = 17\) 근처까지 커져 수백만에 이릅니다. 몇 항만 더하면 터무니없는 값이 나오고, 많이 더해도 큰 수끼리 빼면서 반올림 오차가 커집니다. 그래서 먼저 각을 줄입니다. 360°의 배수를 빼고, 대칭으로 0°~90°로 옮기고, 45°보다 크면 \(\cos(90^\circ - \theta)\)로 바꿉니다. 그러면 \(|x| \le \frac{\pi}{4} \approx 0.785\)라서 테일러급수 4~5항이면 소수 여덟아홉째 자리까지 맞습니다.
  4. 연결테일러급수의 오차 \(\frac{|x|^{n+1}}{(n + 1)!}\)는 \(|x|\)가 작을수록 빨리 줄어듭니다. 원주율 계산에서 \(\tan^{-1}\frac{1}{5}\)을 쓴 것과 같은 생각입니다. "중심 가까이로 옮긴 다음 급수를 쓴다"가 수치 계산의 기본 전략입니다.
  5. 적용각을 바꾸며 줄인 각과 계산 과정을 보세요. 항 수를 1부터 늘리며 두 오차를 비교하세요. 옮기지 않은 계산은 몇 항이 되어야 쓸 만해지나요? 옮긴 계산은 몇 항이면 오차가 \(10^{-8}\)보다 작아지나요?
  6. 판단실제 계산기와 컴퓨터는 테일러다항식을 그대로 쓰기보다, 구간 전체에서 오차가 고르게 작도록 계수를 조정한 다항식이나 CORDIC 같은 다른 방법을 씁니다. 각을 줄이는 단계는 어느 방법에서나 공통입니다.

3.7.2

진자의 주기 공식 \(2\pi\sqrt{L/g}\)는 언제까지 믿을 수 있을까?

\(\sin\theta \approx \theta\) · 시뮬레이션 · 활용
근사 주기 \(2\pi\sqrt{L/g}\)
—
실제 주기
—
10번 흔들린 뒤 어긋남
—

\(L = 1\ \mathrm{m}\), \(g = 9.8\ \mathrm{m/s^2}\), 공기 저항과 줄의 무게는 무시합니다. 실제 운동은 \(\theta'' = -\frac{g}{L}\sin\theta\)를 수치로 풀고, 실제 주기는 산술기하평균을 이용한 정확한 공식으로 구합니다.

  1. 질문진자의 주기는 진폭과 상관없이 \(T = 2\pi\sqrt{\frac{L}{g}}\)이라고 배웁니다(진자의 등시성). 그네를 아주 높이 밀어도 주기가 같을까요?
  2. 복원\(\sin\theta = \theta - \frac{\theta^3}{3!} + \cdots\)이므로 \(\theta\)가 작으면 \(\sin\theta \approx \theta\)이고, 오차는 대략 \(\frac{\theta^3}{6}\)입니다. \(y'' = -\omega^2y\)의 해는 주기 \(\frac{2\pi}{\omega}\)인 사인 곡선입니다.
  3. 설명진자의 운동 방정식은 \(\theta'' = -\frac{g}{L}\sin\theta\)로, 그대로는 풀기 어렵습니다. 테일러급수의 첫 항만 남겨 \(\sin\theta \approx \theta\)로 바꾸면 \(\theta'' = -\frac{g}{L}\theta\)가 되어, 주기 \(2\pi\sqrt{\frac{L}{g}}\)인 단진동이 됩니다. 이것이 등시성의 정체입니다. 실제 주기는 진폭 \(\theta_0\)에 따라 길어지며, 테일러급수의 다음 항까지 쓰면 \(T \approx 2\pi\sqrt{\frac{L}{g}}\left(1 + \frac{\theta_0^2}{16}\right)\)입니다.
  4. 연결진폭 \(10^\circ\)에서 실제 주기는 근사 주기보다 약 0.2 % 길고, \(60^\circ\)에서 약 7 %, \(90^\circ\)에서 약 18 % 깁니다. 진자 시계가 진폭을 작게 유지하는 까닭입니다. 물리 공식 가운데 \(\sin\theta \approx \theta\), \(\sqrt{1 + x} \approx 1 + \frac{x}{2}\)처럼 테일러급수의 앞 항만 남긴 근사가 많습니다.
  5. 적용진폭을 바꾸며 흔들어 보세요. 아래 그래프에서 두 진자가 몇 번 흔들린 뒤 눈에 띄게 어긋나나요? 근사 주기와 실제 주기의 차이가 1 %를 넘는 진폭은 대략 몇 도인가요?
  6. 판단근사가 "괜찮은지"는 얼마나 정확해야 하느냐에 달려 있습니다. 진폭 \(30^\circ\)에서 주기 오차는 약 1.7 %로 한 번 흔들릴 때는 작지만, 하루 동안 흔들리면 진자 시계로는 쓸 수 없을 만큼 쌓입니다. 근사식을 쓸 때는 오차의 크기를 함께 따져야 합니다.

3.7.3

운동 에너지 \(\frac{1}{2}mv^2\)은 상대성 이론의 어떤 근사일까?

이항급수 · 테일러급수의 활용
상대론 \((\gamma - 1)mc^2\)
—
\(\frac{1}{2}mv^2\)의 오차
—
\(+\frac{3}{8}\frac{mv^4}{c^2}\)까지의 오차
—

에너지는 \(mc^2\)을 1로 둔 값입니다. 오차는 상대론의 값에 대한 비율입니다.

  1. 질문특수 상대성 이론에서 물체의 운동 에너지는 \(K = (\gamma - 1)mc^2\), \(\gamma = \frac{1}{\sqrt{1 - v^2/c^2}}\)입니다. 이 식에는 \(\frac{1}{2}mv^2\)이 보이지 않습니다. 그런데도 일상에서는 왜 \(\frac{1}{2}mv^2\)이 잘 맞을까요?
  2. 복원\(f(x) = (1 + x)^{\alpha}\)의 테일러급수(이항급수)는 \(1 + \alpha x + \frac{\alpha(\alpha - 1)}{2!}x^2 + \cdots\ (|x| < 1)\)입니다.
  3. 설명\(\alpha = -\frac{1}{2}\), \(x = -\beta^2\)\((\beta = \frac{v}{c})\)을 넣으면 \[\gamma = (1 - \beta^2)^{-1/2} = 1 + \frac{1}{2}\beta^2 + \frac{3}{8}\beta^4 + \cdots\]이므로 \[K = (\gamma - 1)mc^2 = \frac{1}{2}mv^2 + \frac{3}{8}\frac{mv^4}{c^2} + \cdots\]입니다. 뉴턴의 운동 에너지는 이 급수의 첫 항입니다. 둘째 항은 첫 항의 \(\frac{3}{4}\beta^2\)배이므로, 빛보다 훨씬 느린 일상에서는 무시할 만큼 작습니다.
  4. 연결\(\beta = 0.1\)(초속 3만 km)에서도 \(\frac{1}{2}mv^2\)의 오차는 약 0.75 %입니다. 입자 가속기의 전자처럼 \(\beta\)가 1에 가까우면 급수의 뒤 항들이 커져 뉴턴의 식은 전혀 맞지 않습니다. 새 이론이 옛 이론을 근사로 포함하는 모습을 테일러급수가 보여 줍니다.
  5. 적용\(\beta\)를 키우며 세 곡선이 언제 갈라지는지 보세요. \(\frac{1}{2}mv^2\)의 오차가 1 %를 넘는 \(\beta\)는 대략 얼마인가요? 둘째 항까지 넣으면 같은 정확도를 얼마나 더 빠른 속력까지 유지하나요?
  6. 판단이항급수는 \(|x| < 1\), 곧 \(\beta < 1\)에서만 수렴합니다. \(\beta\)가 1에 가까우면 수렴은 하지만 아주 많은 항이 필요하므로, 이때는 근사 대신 원래 식 \((\gamma - 1)mc^2\)을 써야 합니다.
