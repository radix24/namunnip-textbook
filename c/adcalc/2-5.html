극곡선의 길이와 넓이

극곡선이 둘러싼 넓이는 극에서 뻗은 얇은 부채꼴로 잘라 \(\frac{1}{2}\int r^2\,d\theta\)로 구하고, 길이는 \(\int\sqrt{r^2 + (r')^2}\,d\theta\)로 구합니다. 이 절에서는 부채꼴의 합이 적분으로 다가가는 것을 보고, 곡선이 두 번 그려지는 범위로 적분해 넓이를 두 배로 세는 실수를 찾고, 꺾은선으로 카디오이드의 길이 8을 확인한 뒤 두루마리 휴지에 감긴 종이의 길이를 계산합니다.

먼저 알면 좋은 것 부채꼴의 호의 길이와 넓이정적분과 급수의 합곡선의 길이

2.5.1

극곡선의 넓이는 왜 직사각형이 아니라 부채꼴로 잘라 구할까?

극곡선의 넓이 · 조작 · 판단
\(\sum\frac{1}{2}r^2\Delta\theta\)
—
\(\frac{1}{2}\int r^2\,d\theta\)
—
그림 안쪽의 실제 넓이
—
  1. 질문직교좌표에서는 넓이를 세로로 긴 직사각형으로 잘라 구했습니다. 카디오이드처럼 극을 둘러싼 곡선도 그렇게 잘라야 할까요?
  2. 복원반지름 \(r\), 중심각 \(\Delta\theta\)(라디안)인 부채꼴의 넓이는 \(\frac{1}{2}r^2\Delta\theta\)입니다. 넓이를 잘게 나눈 조각의 합의 극한이 정적분입니다.
  3. 설명극곡선은 극에서 뻗은 방향마다 \(r\)이 정해지므로, 극을 꼭짓점으로 하는 얇은 부채꼴로 자르는 것이 자연스럽습니다. 중심각 \(\Delta\theta\)인 조각은 반지름이 거의 \(f(\theta)\)로 일정한 부채꼴이라 넓이가 \(\frac{1}{2}f(\theta)^2\Delta\theta\)이고, 합의 극한은 \[S = \frac{1}{2}\int_\alpha^\beta \{f(\theta)\}^2\,d\theta\]입니다. 카디오이드 \(1 + \cos\theta\)는 \(\frac{1}{2}\int_0^{2\pi}(1 + \cos\theta)^2d\theta = \frac{3\pi}{2}\)입니다.
  4. 연결\(r^2\)으로 계산하므로 \(r\)이 음수인 부분도 양의 넓이로 셉니다. 그래서 \(\cos 2\theta\)의 꽃잎 4장은 \(0 \le \theta \le 2\pi\)에서 한 번씩 계산되어 \(\frac{\pi}{2}\)가 됩니다.
  5. 적용\(n\)을 늘려 부채꼴의 합이 적분값에 다가가는지 보세요. 그다음 원 \(2\cos\theta\)와 \(\cos 3\theta\)를 \(0 \le \theta \le 2\pi\)로 두고 적분값과 실제 넓이를 비교하세요. 왜 두 배가 되나요? 범위를 \(0 \le \theta \le \pi\)로 바꾸면 어떻게 되나요?
  6. 판단적분 범위는 곡선이 한 번 그려지는 범위로 잡아야 합니다. 원 \(r = 2\cos\theta\)는 \(0 \le \theta \le \pi\)에서 한 바퀴를 다 그리므로, \(2\pi\)까지 적분하면 같은 넓이를 두 번 세어 \(2\pi\)라는 틀린 답이 나옵니다. 넓이 공식을 쓰기 전에 그래프부터 그려 보아야 하는 까닭입니다.

2.5.2

두루마리 휴지를 풀지 않고 길이를 잴 수 있을까?

극곡선의 길이 · 활용
꺾은선의 길이
—
\(\int\sqrt{r^2 + (r')^2}\,d\theta\)
—
—
—

두루마리는 심의 반지름 2 cm, 종이가 한 바퀴에 두께만큼 바깥으로 감긴다고 본 모식입니다. 그림은 감긴 수를 줄여서 그립니다.

  1. 질문두루마리 휴지 한 롤에 몇 m의 종이가 감겨 있을까요? 풀어서 재면 다시 감기 어렵습니다. 바깥 반지름과 종이 두께만 알면 계산할 수 있을까요?
  2. 복원매개변수 곡선의 길이는 \(\int\sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2}\,dt\)입니다. 극곡선은 \(x = r\cos\theta\), \(y = r\sin\theta\)인 매개변수 곡선입니다.
  3. 설명\(x = f(\theta)\cos\theta\), \(y = f(\theta)\sin\theta\)를 미분해 제곱하여 더하면 교차항이 지워져 \(\left(\frac{dx}{d\theta}\right)^2 + \left(\frac{dy}{d\theta}\right)^2 = f(\theta)^2 + f'(\theta)^2\)이 됩니다. 그래서 극곡선의 길이는 \[L = \int_\alpha^\beta\sqrt{f(\theta)^2 + f'(\theta)^2}\,d\theta\]입니다. 카디오이드는 \(\sqrt{2 + 2\cos\theta} = 2\left|\cos\frac{\theta}{2}\right|\)이므로 길이가 정확히 8입니다. 두루마리의 단면은 한 바퀴마다 두께 \(d\)만큼 커지는 아르키메데스 나선 \(r = r_0 + \frac{d}{2\pi}\theta\)입니다.
  4. 연결나선의 적분은 손으로 계산하기 번거롭지만, \(r'\)이 \(r\)에 비해 아주 작으므로 \(L \approx \int r\,d\theta\)이고, 이는 "단면의 넓이 ÷ 두께" \(\frac{\pi(R^2 - r_0^2)}{d}\)과 거의 같습니다. 종이를 펼쳐 얇은 띠로 놓아도 넓이는 같다는 생각과 맞습니다.
  5. 적용카디오이드에서 마디 수를 늘려 꺾은선의 길이가 8에 다가가는지 보세요. 두루마리에서는 적분값과 넓이 어림이 몇 % 다른지 보세요. 두께를 두 배로 하면 길이는 어떻게 되나요?
  6. 판단꺾은선은 언제나 곡선보다 짧으므로 마디 수를 늘리면 아래에서 참값에 다가갑니다. 실제 휴지는 눌리거나 느슨하게 감겨 두께가 일정하지 않으므로, 이 계산은 대략적인 값입니다.
