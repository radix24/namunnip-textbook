테일러다항식과 테일러급수

한 점에서 함숫값, 기울기, 휘는 정도, 그리고 더 높은 계도함수까지 원래 함수와 같게 만든 다항식이 테일러다항식입니다. 차수를 끝없이 올린 급수가 테일러급수입니다. 이 절에서는 막대로 \(\cos x\)를 흉내 내는 이차식을 직접 만들어 테일러다항식과 겨루고, 차수를 올릴 때 다항식이 원래 함수를 어디까지 따라가는지, 따라가지 못하는 함수는 어떤 것인지 살펴봅니다.

3.6.1

이차식 하나로 \(\cos x\)를 가장 잘 흉내 내려면?

테일러다항식 · 만들기 · 예측 → 확인
\(x = 0.1\)에서 오차 (내 식)
—
\(x = 0.1\)에서 오차 (테일러)
?
\([-1, 1]\)에서 최대 오차 (내 식)
—
  1. 질문계산기에는 \(\cos\) 표가 없습니다. 덧셈과 곱셈만으로 계산하는 다항식으로 \(\cos x\)를 흉내 낼 수 있다면 편리합니다. \(x = 0\) 근처에서 \(\cos x\)와 가장 비슷한 이차식 \(c_0 + c_1x + c_2x^2\)은 무엇일까요? 막대로 직접 맞춰 보세요.
  2. 복원접선 \(y = f(a) + f'(a)(x - a)\)는 \(x = a\)에서 함숫값과 기울기가 \(f\)와 같은 일차식입니다. 이계도함수는 그래프가 휘는 정도를 나타냅니다.
  3. 설명"0 근처에서 가장 비슷하다"는 것을 "0에서 함숫값, 기울기, 휘는 정도가 모두 같다"로 정하면 \(p(0) = f(0)\), \(p'(0) = f'(0)\), \(p''(0) = f''(0)\)이고, \(p''(0) = 2c_2\)이므로 \[c_0 = f(0),\quad c_1 = f'(0),\quad c_2 = \frac{f''(0)}{2}\]입니다. 일반적으로 \(n\)계도함수까지 맞춘 \(T_n(x) = \sum_{k=0}^{n}\frac{f^{(k)}(a)}{k!}(x - a)^k\)을 테일러다항식이라고 합니다. \(\cos x\)에서는 \(T_2(x) = 1 - \frac{x^2}{2}\)입니다.
  4. 연결테일러다항식의 차수를 끝없이 늘린 급수 \(\sum\frac{f^{(k)}(a)}{k!}(x - a)^k\)을 테일러급수라고 합니다. \(\cos x = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \cdots\), \(e^x = 1 + x + \frac{x^2}{2!} + \cdots\)은 모든 \(x\)에서 원래 함수와 같습니다.
  5. 적용막대로 \(\cos x\)에 가장 잘 맞는 이차식을 만든 다음 테일러다항식과 비교하세요. \(x = 0.1\)에서는 어느 쪽 오차가 작은가요? \([-1, 1]\) 전체의 최대 오차는 어떤가요? \(e^x\)로도 해 보세요.
  6. 판단테일러다항식은 중심 근처에서 가장 잘 맞도록 만든 것이지, 넓은 구간 전체에서 최대 오차가 가장 작은 다항식은 아닙니다. 막대로 맞춘 식이 \([-1, 1]\)의 최대 오차는 더 작을 수도 있습니다. 구간 전체를 고르게 맞추는 다항식은 다른 방법(최소최대 근사)으로 만듭니다.

3.6.2

차수를 올리면 테일러다항식은 어디까지 함수를 따라갈까?

테일러다항식과 테일러급수 · 조작

  1. 질문\(\sin x\)의 테일러다항식은 차수를 올릴수록 더 넓은 범위에서 \(\sin x\)를 따라갑니다. 차수를 끝없이 올리면 모든 함수를 어디서나 따라갈 수 있을까요?
  2. 복원\(T_n(x) = \sum_{k=0}^{n}\frac{f^{(k)}(a)}{k!}(x - a)^k\)는 \(x = a\)에서 \(n\)계도함수까지 \(f\)와 같은 다항식입니다.
  3. 설명오차 \(R_n(x) = f(x) - T_n(x)\)는 \(a\)와 \(x\) 사이의 어떤 \(c\)에 대해 \[R_n(x) = \frac{f^{(n+1)}(c)}{(n + 1)!}(x - a)^{n+1}\]입니다(테일러 정리). \(\sin x\), \(e^x\)는 도함수가 제한되거나 천천히 커지므로 \((n + 1)!\)이 이겨서 모든 \(x\)에서 \(R_n \to 0\)이고, 테일러급수가 원래 함수와 같습니다. \(\ln(1 + x)\)는 \(f^{(n+1)}\)이 \(n!\)처럼 커져서 \(|x| < 1\)에서만 따라가고, \(x > 1\)에서는 차수를 올릴수록 오히려 크게 벗어납니다.
  4. 연결아래 그림은 오차를 로그 눈금으로 보여 줍니다. 오차의 골짜기가 중심 \(a\)에 있고, 차수를 올릴 때 골짜기가 넓어지면 테일러급수가 그 범위에서 함수로 수렴하는 것입니다. 중심을 옮기면 같은 차수라도 맞는 곳이 옮겨 갑니다.
  5. 적용\(\sin x\)에서 \(n\)을 1, 3, 5, …로 올리며 맞는 범위가 넓어지는지 보세요. \(\ln(1 + x)\)에서는 \(x = 1.5\) 근처가 어떻게 되나요? 중심을 \(a = 1\)로 옮기면 어떻게 바뀌나요? 마지막 보기 \(e^{-1/x^2}\)의 테일러다항식은 무엇인가요?
  6. 판단\(f(x) = e^{-1/x^2}\ (f(0) = 0)\)은 \(x = 0\)에서 모든 계도함수가 0이라 테일러급수가 \(0 + 0 + \cdots = 0\)입니다. 급수는 모든 \(x\)에서 수렴하지만 \(x \ne 0\)에서 원래 함수와 다릅니다. "테일러급수가 수렴한다"와 "테일러급수가 그 함수와 같다"는 다른 말입니다.
