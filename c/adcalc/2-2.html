극곡선의 대칭성과 그래프

\(r = f(\theta)\)꼴의 방정식이 나타내는 곡선을 극곡선이라고 합니다. 각 \(\theta\) 방향으로 \(f(\theta)\)만큼 간 점을 이으면 카디오이드, 장미, 나선 같은 모양이 생깁니다. 이 절에서는 보통의 그래프와 극곡선을 나란히 그려 두 그림을 잇고, 대칭성으로 그리는 수고를 줄이고, 장미 곡선의 꽃잎 수를 맞혀 보고, 무대용 마이크가 뒤쪽 소리를 덜 받는 까닭을 카디오이드로 설명합니다.

2.2.1

\(r = f(\theta)\)의 그래프를 극좌표로 옮기면 어떤 모양이 될까?

극곡선의 그래프와 대칭성 · 조작
극축(\(x\)축) 대칭
—
\(\theta = \frac{\pi}{2}\)(\(y\)축) 대칭
—
극(원점) 대칭
—

대칭 칸의 앞 글자는 식 판정(\(f(-\theta) = f(\theta)\), \(f(\pi - \theta) = f(\theta)\), \(f(\theta + \pi) = f(\theta)\)), 뒤 글자는 그림을 실제로 뒤집어 겹쳐 본 결과입니다.

  1. 질문\(r = 1 + \cos\theta\)는 보통의 좌표평면에서는 물결 모양 그래프입니다. 이 식을 "각 \(\theta\) 방향으로 \(r\)만큼"이라고 읽어 극좌표로 그리면 어떤 모양이 될까요?
  2. 복원극좌표 \((r, \theta)\)는 \(\theta\) 방향으로 \(r\)만큼 간 점이고, \(r < 0\)이면 반대 방향입니다. 함수의 그래프를 그릴 때는 증가, 감소, 최댓값, 0이 되는 곳을 먼저 봅니다.
  3. 설명\(\theta\)를 바늘처럼 돌리며, 왼쪽 그래프에서 읽은 높이 \(r\)만큼 바늘 끝을 늘였다 줄였다 하면 극곡선이 그려집니다. 왼쪽 그래프가 0이 되는 \(\theta\)에서 극곡선은 극을 지나고, \(r\)이 음수인 구간은 반대쪽에 그려집니다. 그래서 \(1 + 2\cos\theta\)는 안쪽에 작은 고리가 생깁니다. 대칭성을 먼저 알면 그리는 수고가 줄어듭니다. \(f(-\theta) = f(\theta)\)이면 극축에, \(f(\pi - \theta) = f(\theta)\)이면 \(\theta = \frac{\pi}{2}\)에, \(f(\theta + \pi) = f(\theta)\)이면 극에 대칭입니다.
  4. 연결\(1 + \cos\theta\)처럼 하트 모양 곡선은 카디오이드(심장형), \(\cos 2\theta\), \(\sin 3\theta\)는 장미 곡선, \(\frac{\theta}{2}\)는 아르키메데스 나선이라고 부릅니다. 직교좌표로 쓰면 복잡한 이 곡선들이 극좌표에서는 짧은 식 하나입니다.
  5. 적용보기마다 처음부터 그리기를 눌러, 왼쪽 그래프의 어느 부분이 오른쪽 곡선의 어느 부분이 되는지 따라가 보세요. \(1 + 2\cos\theta\)의 안쪽 고리는 \(\theta\)가 얼마일 때 그려지나요? \(\sin 3\theta\)는 \(\theta\)가 \(\pi\)를 넘으면 무슨 일이 생기나요?
  6. 판단대칭의 식 판정은 충분조건일 뿐입니다. \(\sin 2\theta\)는 \(f(-\theta) = -f(\theta)\)라서 식 판정은 "아니오"이지만, 그림은 극축에 대칭입니다. 같은 점을 \((r, \theta)\)와 \((-r, \theta + \pi)\)처럼 여러 이름으로 부를 수 있기 때문입니다. 식 판정이 실패하면 그림으로 다시 확인해야 합니다.

2.2.2

\(r = \cos k\theta\)의 꽃잎은 몇 장일까?

장미 곡선 · 예측 → 확인 · 도전

지금 \(\theta\)
—
그려진 꽃잎
—
맞힌 문제
0
  1. 질문\(r = \cos 2\theta\)는 꽃잎이 4장, \(r = \cos 3\theta\)는 3장입니다. \(k\)가 커질수록 꽃잎이 많아지는데, \(k\)장이 아니라 \(2k\)장일 때가 있습니다. 어떤 규칙일까요?
  2. 복원\(\cos k\theta\)의 주기는 \(\frac{2\pi}{k}\)입니다. \((r, \theta)\)와 \((-r, \theta + \pi)\)는 같은 점입니다.
  3. 설명\(|\cos k\theta|\)가 0에서 1로 올랐다 0으로 내려오는 한 번(길이 \(\frac{\pi}{k}\))이 꽃잎 하나를 그립니다. \(0 \le \theta < 2\pi\)에서 이런 구간은 \(2k\)개입니다. 그런데 \(\cos k(\theta + \pi) = \cos(k\theta + k\pi)\)이므로 \(k\)가 홀수이면 \(r\)의 부호만 바뀌어, \(\theta + \pi\)일 때 \((-r, \theta + \pi)\), 곧 \(\theta\)일 때와 같은 점을 다시 그립니다. 그래서 \(k\)가 홀수이면 꽃잎 \(k\)장을 \(0 \le \theta \le \pi\)에서 다 그리고 나머지는 덧그립니다. \(k\)가 짝수이면 \(2k\)장이 모두 다른 곳에 생기고 \(2\pi\)까지 돌아야 다 그려집니다.
  4. 연결이렇게 "같은 점을 여러 이름으로 부를 수 있다"는 극좌표의 성질이 그래프의 모양을 정합니다. 두 극곡선의 교점을 구할 때도 이 성질 때문에 식을 풀어서 나오지 않는 교점이 생깁니다.
  5. 적용\(k\)를 고르고 꽃잎 수와 필요한 \(\theta\)의 범위를 예측한 뒤 그려서 확인하세요. 여섯 문제를 모두 맞히면 규칙을 찾은 것입니다. 홀수일 때 \(\pi\)를 넘어서 그리는 동안 곡선은 어떻게 움직이나요?
  6. 판단"\(\theta\)가 \(0\)부터 \(2\pi\)까지 돌면 곡선이 한 번 그려진다"는 생각은 극곡선에서 틀리기 쉽습니다. 홀수 장미는 두 번 그려지고, 나선 \(r = \theta\)는 \(2\pi\)를 넘어서도 계속 새로운 점을 그립니다. 넓이를 구할 때 이 차이를 놓치면 두 배로 셉니다.

2.2.3

무대용 마이크는 왜 뒤쪽 소리를 잘 받지 않을까?

카디오이드 · 극곡선 · 활용
소리 방향 (앞에서 잰 각)
—
감도 \(|r|\)
—
감도 (dB)
—

주황 점(스피커)을 끌어 옮기세요. 감도는 앞(위쪽)에서 오는 소리를 1로 둔 값이고, dB는 \(20\log_{10}|r|\)입니다. 점선은 감도가 0인 방향입니다.

  1. 질문공연장에서 가수 앞의 모니터 스피커 소리가 마이크로 다시 들어가면 "삐–" 하는 하울링이 생깁니다. 그래서 무대용 마이크는 앞소리는 잘 받고 뒷소리는 덜 받도록 만듭니다. 이 "방향에 따른 감도"를 어떻게 나타낼까요?
  2. 복원극곡선 \(r = f(\theta)\)는 각 방향으로 \(f(\theta)\)만큼 간 점들입니다. \(r = 1 + \cos\theta\)는 카디오이드입니다.
  3. 설명마이크의 감도를 방향마다 재어 극좌표로 그린 것을 지향 특성(polar pattern)이라고 합니다. 흔한 마이크들은 \[r = a + (1 - a)\cos\theta\ \ (0 \le a \le 1)\]꼴로 잘 나타납니다(\(\theta\)는 정면에서 잰 각). \(a = 1\)이면 원(모든 방향 같음), \(a = 0.5\)이면 카디오이드로 바로 뒤(\(\theta = \pi\))의 감도가 0입니다. \(a\)가 더 작으면 \(r\)이 음수가 되는 방향이 생겨 뒤쪽에 작은 고리가 생깁니다. 감도가 0인 방향은 \(\cos\theta = -\frac{a}{1 - a}\)에서 생깁니다.
  4. 연결이 곡선은 극곡선의 대칭성으로 그리기 쉽습니다. \(\cos\)만 들어 있으므로 정면 방향 축에 대칭이고, 반쪽만 그리면 됩니다. \(r\)이 음수인 고리는 그 방향의 소리가 반대 위상으로 들어온다는 뜻입니다.
  5. 적용카디오이드에서 스피커를 바로 뒤에 두어 감도가 0이 되는지 보세요. 하이퍼카디오이드로 바꾸면 감도가 0인 방향은 몇 도인가요? 무대에서 모니터 스피커를 마이크 바로 뒤가 아니라 비스듬히 뒤에 두는 경우가 있는 까닭을 설명해 보세요.
  6. 판단실제 마이크의 지향 특성은 소리의 높낮이(주파수)에 따라 달라지고, 이 식은 이상화한 모형입니다. 또 이 그림은 평면 단면일 뿐, 실제 감도는 마이크 축 둘레로 돌린 입체 모양입니다.
