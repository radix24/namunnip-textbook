쌍곡선함수의 부정적분

도함수를 거꾸로 읽으면 \(\int \cosh x\,dx = \sinh x + C\), \(\int \sinh x\,dx = \cosh x + C\)입니다. 쓰임새가 더 큰 것은 치환입니다. \(\sqrt{x^2 + 1}\)이 들어간 적분은 \(x = \sinh t\)로 놓으면 \(\cosh^2 t - \sinh^2 t = 1\) 덕분에 근호가 사라집니다. 이 절에서는 근호의 꼴에 맞는 치환을 고르고, 두 전봇대 사이에 늘어진 전선의 길이를 쌍곡선함수의 적분으로 구합니다.

1.4.1

근호 속의 \(x^2 + 1\)을 없애는 치환은?

쌍곡선함수 치환 · 고르기 · 검산

어떤 치환이 근호를 없앨까요?

칠한 넓이 (수치)
—
치환으로 구한 값
—
구한 식
—
  1. 질문\(\int\frac{dx}{\sqrt{1 - x^2}}\)은 \(x = \sin t\)로 치환하면 \(1 - \sin^2 t = \cos^2 t\) 덕분에 근호가 사라졌습니다. \(\sqrt{x^2 + 1}\)이나 \(\sqrt{x^2 - 1}\)도 사라지게 하는 치환이 있을까요?
  2. 복원\(\cosh^2 t - \sinh^2 t = 1\), \((\sinh t)' = \cosh t\), \((\cosh t)' = \sinh t\). 치환적분법: \(x = g(t)\)이면 \(dx = g'(t)\,dt\).
  3. 설명항등식을 두 가지로 읽으면 됩니다. \(1 + \sinh^2 t = \cosh^2 t\)이므로 \(x = \sinh t\)이면 \(\sqrt{x^2 + 1} = \cosh t\)입니다. \(\cosh^2 t - 1 = \sinh^2 t\)이므로 \(x = \cosh t\ (t \ge 0)\)이면 \(\sqrt{x^2 - 1} = \sinh t\)입니다. 예를 들어 \(dx = \cosh t\,dt\)이므로 \[\int\frac{dx}{\sqrt{x^2 + 1}} = \int\frac{\cosh t}{\cosh t}\,dt = t + C\]이고, \(t = \sinh^{-1} x = \ln\left(x + \sqrt{x^2 + 1}\right)\)입니다. 넷째 적분은 \(\int\cosh^2 t\,dt = \int\frac{1 + \cosh 2t}{2}\,dt\)가 되어 \(\frac{1}{2}\left(x\sqrt{x^2 + 1} + \sinh^{-1} x\right) + C\)입니다.
  4. 연결기본 적분 공식 \(\int\cosh x\,dx = \sinh x + C\), \(\int\sinh x\,dx = \cosh x + C\), \(\int\frac{dx}{\cosh^2 x} = \tanh x + C\)는 도함수 공식을 거꾸로 읽은 것입니다. \(\sqrt{x^2 + 1}\)은 \(x = \tan t\)로도 없앨 수 있지만, 그러면 \(\int\sec t\,dt\) 같은 더 까다로운 적분이 남습니다.
  5. 적용네 적분마다 근호를 없애는 치환을 고르세요. 맞히면 구한 식이 나타납니다. \(b\)를 움직이며 칠한 넓이(수치)와 식의 값이 같은지 확인하세요. 셋째 적분에서 \(b\)를 1에 가깝게 하면 피적분함수는 어떻게 되나요?
  6. 판단\(x = \cosh t\)로 치환할 때는 \(x \ge 1\)이어야 하고, \(\sqrt{\sinh^2 t} = \sinh t\)가 되려면 \(t \ge 0\)으로 잡아야 합니다. 치환의 범위를 확인하지 않으면 부호가 틀린 답이 나옵니다.

1.4.2

100 m 사이에 전선을 1 m만 더 길게 걸면 얼마나 처질까?

\(\cosh\)의 적분 · 곡선의 길이 · 예측 → 확인

현수선의 처짐
?
\(a\) (m)
?
\(2a\sinh\frac{50}{a}\) (m)
?

전선을 현수선 \(y = a\cosh\frac{x}{a}\)로 보고, 길이가 주어진 값이 되는 \(a\)를 수치로 찾습니다. 그림의 세로는 가로보다 2배 늘였습니다.

  1. 질문두 기둥 사이가 100 m인데 전선을 101 m로, 곧 1 %만 길게 걸었습니다. 전선 한가운데는 얼마나 처질까요? 확인하기 전에 짐작해서 예측 막대를 맞추어 보세요.
  2. 복원곡선 \(y = f(x)\)의 \(x = p\)부터 \(q\)까지의 길이는 \(\int_p^q\sqrt{1 + \{f'(x)\}^2}\,dx\)입니다. \(\cosh^2 u - \sinh^2 u = 1\)이고 \(\int\cosh\frac{x}{a}\,dx = a\sinh\frac{x}{a} + C\)입니다.
  3. 설명\(y = a\cosh\frac{x}{a}\)이면 \(y' = \sinh\frac{x}{a}\)이고 \(\sqrt{1 + \sinh^2\frac{x}{a}} = \cosh\frac{x}{a}\)이므로 근호가 깨끗이 사라집니다. 그래서 \(-d\)부터 \(d\)까지의 길이는 \[L = \int_{-d}^{d}\cosh\frac{x}{a}\,dx = 2a\sinh\frac{d}{a}\]이고, 처짐은 \(s = a\left(\cosh\frac{d}{a} - 1\right)\)입니다. 처짐이 작으면 \(L \approx 2d + \frac{8s^2}{3 \cdot 2d}\)로 어림할 수 있어, 늘어난 길이는 처짐의 제곱에 비례합니다. 거꾸로 말하면 처짐은 늘어난 길이의 제곱근에 비례해 생각보다 크게 생깁니다.
  4. 연결현수선의 길이가 이렇게 간단한 식으로 나오는 것은 \(\cosh\)의 도함수와 적분이 다시 쌍곡선함수이기 때문입니다. 송전선, 현수교 주케이블을 설계할 때 처짐과 길이, 장력의 관계를 이 식으로 계산합니다.
  5. 적용101 m에서 예측한 뒤 확인하세요. 처짐은 약 6 m입니다. 예측과 얼마나 달랐나요? 길이를 100.1 m(0.1 % 길게)로 바꾸면 처짐은 1 m보다 클까요, 작을까요? 예측한 다음 확인하세요.
  6. 판단실제 전선은 무게 때문에 조금 늘어나고, 여름에는 열팽창으로 길이가 늘어 더 처집니다. 늘어난 길이가 아주 작아도 처짐이 크게 바뀌므로, 송전선은 계절별 온도를 고려해 처짐을 계산합니다. 이 카드는 늘어나지 않는 전선을 가정한 모형입니다.
