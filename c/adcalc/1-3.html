쌍곡선함수의 도함수

\(\cosh x\)와 \(\sinh x\)는 \(e^x\)와 \(e^{-x}\)로 만든 함수이므로 지수함수의 도함수에서 바로 도함수가 나옵니다. 결과는 삼각함수와 닮았지만 부호 하나가 다릅니다. 이 절에서는 접선의 기울기를 따라가며 도함수를 확인하고, 삼각함수를 흉내 내다 생기는 계산 오류를 찾고, 공기 저항을 받으며 떨어지는 스카이다이버의 속도가 \(\tanh\)로 나타나는 까닭을 미분으로 확인합니다.

먼저 알면 좋은 것 지수함수와 로그함수의 도함수합성함수의 미분법역함수의 미분법몫의 미분법

1.3.1

\(\cosh x\)의 접선의 기울기를 모으면 어떤 그래프가 될까?

쌍곡선함수의 도함수 · 조작 · 발견
접선의 기울기
—
겹친 함수의 값
—
모은 점
0
  1. 질문\(\cosh x\)의 그래프는 \(x = 0\)에서 평평하고, 오른쪽으로 갈수록 가파르게 오르며, 왼쪽에서는 내려갑니다. 접선의 기울기만 모아 그래프로 그리면 어떤 함수가 나올까요?
  2. 복원\((e^x)' = e^x\), \((e^{-x})' = -e^{-x}\)이고, 미분은 합과 실수배를 지킵니다. 몫의 미분법은 \(\left(\frac{f}{g}\right)' = \frac{f'g - fg'}{g^2}\)입니다.
  3. 설명정의에서 바로 \[(\cosh x)' = \frac{e^x - e^{-x}}{2} = \sinh x\] \[(\sinh x)' = \frac{e^x + e^{-x}}{2} = \cosh x\]입니다. 몫의 미분법과 \(\cosh^2 x - \sinh^2 x = 1\)을 쓰면 \((\tanh x)' = \frac{1}{\cosh^2 x}\)입니다(\(\frac{1}{\cosh x}\)을 \(\operatorname{sech} x\)로 씁니다). 삼각함수와 모양은 같지만, \((\cos x)' = -\sin x\)와 달리 \((\cosh x)' = \sinh x\)에는 음의 부호가 없습니다.
  4. 연결역함수의 미분법으로 \((\sinh^{-1} x)' = \frac{1}{\sqrt{x^2 + 1}}\), \((\cosh^{-1} x)' = \frac{1}{\sqrt{x^2 - 1}}\ (x > 1)\), \((\tanh^{-1} x)' = \frac{1}{1 - x^2}\ (|x| < 1)\)도 얻습니다. 두 번 미분하면 \((\cosh x)'' = \cosh x\)이므로 \(\cosh\)와 \(\sinh\)는 미분방정식 \(y'' = y\)의 해입니다. \(\cos\)와 \(\sin\)이 \(y'' = -y\)의 해인 것과 짝을 이룹니다.
  5. 적용\(\cosh x\)를 고르고 \(x\)를 움직이거나 쓸기 단추를 눌러 기울기 점을 모으세요. 점들이 어떤 그래프를 이루는지 짐작한 다음 겹쳐 보세요. \(\tanh x\)의 기울기는 어디에서 가장 크고, 그 값은 얼마인가요? \(\cos x\)의 기울기 점과 비교하면 무엇이 다른가요?
  6. 판단쌍곡선함수의 공식은 삼각함수 공식에서 부호만 몇 개 바꾸면 되는 경우가 많지만, 어느 부호가 바뀌는지는 외워 맞히는 것이 아니라 정의에서 확인해야 합니다. 예를 들어 \(\cos^2 + \sin^2 = 1\)은 \(\cosh^2 - \sinh^2 = 1\)로 바뀌지만 \((\sin)' = \cos\)는 \((\sinh)' = \cosh\)로 그대로입니다.

1.3.2

이 미분 풀이, 어디가 틀렸을까?

쌍곡선함수의 도함수 · 오류 찾기

처음 틀린 줄을 누르세요. 틀린 곳이 없으면 마지막 줄을 누르세요. 두 그래프가 겹치는지가 단서입니다.

  1. \(f(x) = x\cosh x\)를 곱의 미분법으로 미분한다.방법은 맞습니다.
  2. \(f'(x) = \cosh x + x(\cosh x)' = \cosh x - x\sinh x\)이다.여기가 틀렸습니다. \((\cosh x)' = \sinh x\)이고 음의 부호가 없습니다. \(\cos x\)의 공식을 흉내 냈습니다. 바른 답은 \(\cosh x + x\sinh x\)입니다.
  3. 따라서 \(f'(0) = 1\)이다.\(x = 0\)에서는 둘째 항이 0이라 우연히 맞았습니다. 다른 점에서는 틀린 값이 나옵니다.
  4. 이 풀이에는 틀린 곳이 없다.두 그래프가 \(x = 0\)에서만 만나는 것을 보세요.
  1. \(f(x) = \sinh 3x\)는 \(\sinh u\)와 \(u = 3x\)의 합성함수이다.맞습니다.
  2. \((\sinh u)' = \cosh u\)이므로 \(f'(x) = \cosh 3x\)이다.여기가 틀렸습니다. 합성함수의 미분법에서 \(\frac{du}{dx} = 3\)을 곱해야 합니다. 바른 답은 \(3\cosh 3x\)입니다.
  3. \(f'(0) = \cosh 0 = 1\)이다.앞 줄의 잘못을 이어받았습니다. 실제 \(f'(0) = 3\)입니다.
  4. 이 풀이에는 틀린 곳이 없다.원점에서 두 그래프의 높이를 비교하세요.
  1. \(\tanh x = \frac{\sinh x}{\cosh x}\)에 몫의 미분법을 쓴다.맞습니다.
  2. \((\tanh x)' = \frac{\cosh x \cdot \cosh x - \sinh x \cdot \sinh x}{\cosh^2 x}\)이다.맞습니다. \((\sinh x)' = \cosh x\), \((\cosh x)' = \sinh x\)를 바르게 넣었습니다.
  3. \(\cosh^2 x - \sinh^2 x = 1\)이므로 \((\tanh x)' = \frac{1}{\cosh^2 x}\)이다.맞습니다.
  4. 이 풀이에는 틀린 곳이 없다.맞습니다. 두 그래프가 완전히 겹칩니다. \(\frac{1}{\cosh^2 x} = 1 - \tanh^2 x\)로 쓸 수도 있습니다.
  1. \(y = \sinh^{-1} x\)로 놓으면 \(x = \sinh y\)이다.맞습니다.
  2. 양변을 \(y\)로 미분하면 \(\frac{dx}{dy} = \cosh y\)이므로 \(\frac{dy}{dx} = \frac{1}{\cosh y}\)이다.역함수의 미분법을 바르게 썼습니다.
  3. \(\cosh^2 y = \sinh^2 y - 1 = x^2 - 1\)이므로 \(\frac{dy}{dx} = \frac{1}{\sqrt{x^2 - 1}}\)이다.여기가 틀렸습니다. \(\cosh^2 y - \sinh^2 y = 1\)이므로 \(\cosh^2 y = 1 + \sinh^2 y = 1 + x^2\)입니다. 바른 답은 \(\frac{1}{\sqrt{x^2 + 1}}\)입니다. 이 풀이의 답은 \(|x| < 1\)에서 정의되지도 않습니다.
  4. 이 풀이에는 틀린 곳이 없다.풀이의 그래프가 \(-1 < x < 1\)에서 끊긴 것을 보세요. 원래 함수는 실수 전체에서 미분가능합니다.
  1. 질문쌍곡선함수의 미분 공식은 삼각함수와 닮아서 빨리 익숙해집니다. 그런데 닮았기 때문에 생기는 실수도 있습니다. 어디에서 틀리기 쉬울까요?
  2. 복원\((\sinh x)' = \cosh x\), \((\cosh x)' = \sinh x\), \(\cosh^2 x - \sinh^2 x = 1\). 합성함수의 미분법 \(\{f(g(x))\}' = f'(g(x))g'(x)\)와 역함수의 미분법 \(\frac{dy}{dx} = \frac{1}{dx/dy}\).
  3. 설명틀리기 쉬운 곳은 세 군데입니다. ① \(\cos\)처럼 \((\cosh x)'\)에 음의 부호를 붙인다(풀이 1). ② 합성함수의 속미분을 빠뜨린다(풀이 2). ③ \(\cos^2 + \sin^2 = 1\)을 흉내 내 \(\cosh^2 y\)를 잘못 바꾼다(풀이 4). 계산이 맞는지 의심스러우면 \(x = 0\) 한 점이 아니라 여러 점에서 기울기를 확인해야 합니다. 풀이 1은 \(x = 0\)에서만 우연히 맞습니다.
  4. 연결풀이 4의 바른 결과 \((\sinh^{-1} x)' = \frac{1}{\sqrt{x^2 + 1}}\)을 거꾸로 읽으면 \(\int \frac{dx}{\sqrt{x^2 + 1}} = \sinh^{-1} x + C\)입니다. 다음 절의 적분에서 바로 씁니다.
  5. 적용네 풀이에서 처음 틀린 줄을 찾으세요. 실선(풀이의 답)과 점선(실제 기울기)이 어디에서 갈라지나요? 풀이 3에서는 두 선이 겹치나요?
  6. 판단한 점에서 값이 맞는다고 도함수가 맞는 것은 아닙니다. 반대로 그래프 두 개가 그림의 범위에서 겹쳐 보여도 증명은 아닙니다. 그래프는 틀린 곳을 찾는 단서이고, 맞다는 근거는 계산의 각 단계입니다.

1.3.3

스카이다이버의 속도는 왜 끝없이 빨라지지 않을까?

\(\tanh\)의 도함수 · 활용
속도 \(v\) (m/s)
—
접선 기울기 \(v'\)
—
\(g\left(1 - \frac{v^2}{v_T^2}\right)\)
—
\(v \div v_T\)
—

\(g = 9.8\ \mathrm{m/s^2}\). 공기 저항이 속도의 제곱에 비례한다는 모형입니다. 실제 저항은 자세, 고도에 따른 공기 밀도에 따라 달라집니다.

  1. 질문공기 저항이 없다면 4000 m 높이에서 뛰어내린 사람은 땅에 닿을 때 초속 280 m 가까이 됩니다. 실제 스카이다이버는 몇 초 뒤부터 거의 일정한 속도로 떨어집니다. 이 속도 변화를 어떤 함수로 나타낼 수 있을까요?
  2. 복원\((\tanh x)' = \frac{1}{\cosh^2 x} = 1 - \tanh^2 x\)이고, \(\tanh x\)는 \(x \to \infty\)일 때 1에 다가갑니다. 가속도는 속도의 순간변화율입니다.
  3. 설명공기 저항이 속도의 제곱에 비례하면 운동 방정식은 \(mv' = mg - kv^2\), 곧 \(v' = g\left(1 - \frac{v^2}{v_T^2}\right)\)입니다. 여기서 \(v_T = \sqrt{\frac{mg}{k}}\)는 저항과 무게가 같아지는 종단 속도입니다. \(v = v_T\tanh\frac{gt}{v_T}\)로 놓고 미분하면 \[v' = v_T \cdot \frac{g}{v_T}\left(1 - \tanh^2\frac{gt}{v_T}\right) = g\left(1 - \frac{v^2}{v_T^2}\right)\]이므로 이 함수가 방정식을 만족합니다. 처음(\(t\)가 작을 때)에는 \(\tanh x \approx x\)라서 \(v \approx gt\)이고, 시간이 지나면 \(v_T\)에 다가갑니다.
  4. 연결배를 아래로 한 자세의 스카이다이버의 종단 속도는 약 55 m/s(시속 약 200 km)로 알려져 있습니다. 머리를 아래로 하면 저항이 줄어 더 빨라지고, 낙하산을 펴면 저항이 크게 늘어 종단 속도가 수 m/s로 떨어집니다. 이런 방정식을 미분방정식이라 하고, 4대단원에서 직접 풉니다.
  5. 적용\(t\)를 움직이며 접선의 기울기 \(v'\)와 \(g\left(1 - \frac{v^2}{v_T^2}\right)\)이 늘 같은지 확인하세요. \(v_T = 55\)일 때 종단 속도의 95 %에 이르는 시각은 몇 초인가요? \(v_T\)를 키우면 그 시각은 어떻게 바뀌나요?
  6. 판단속도가 \(v_T\)에 "도달"하는 시각은 없습니다. \(\tanh\)는 1에 끝없이 다가갈 뿐 1이 되지 않습니다. 또 이 모형에서 저항을 속도에 정비례(\(kv\))로 바꾸면 해는 \(\tanh\)가 아니라 지수함수 \(v_T(1 - e^{-gt/v_T})\)가 됩니다. 저항이 속도의 몇 제곱에 비례하는지는 물체의 크기와 빠르기에 따라 다릅니다.
