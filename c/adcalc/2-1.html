극좌표

평면 위의 점은 \((x, y)\) 말고도 "원점에서 얼마나 멀리, 어느 방향으로"라는 두 수로 나타낼 수 있습니다. 이것이 극좌표 \((r, \theta)\)입니다. 레이더, 항해, 로봇 팔처럼 한 점을 중심으로 돌며 재는 곳에서는 극좌표가 더 자연스럽습니다. 이 절에서는 레이더 화면에서 극좌표로 목표를 찾고, 극좌표와 직교좌표를 오가며 바꿀 때 틀리기 쉬운 곳을 찾습니다.

2.1.1

레이더는 왜 \((x, y)\) 대신 거리와 방향으로 위치를 알려 줄까?

극좌표 · 도전

문제
1 / 6
누른 곳과의 거리
—
직교좌표 \((x, y)\)
?

동심원 한 칸은 1, 방사선 한 칸은 \(30^\circ = \frac{\pi}{6}\)입니다. 목표에서 0.3 안쪽을 누르면 맞힌 것으로 칩니다.

  1. 질문레이더는 안테나를 돌리며 전파를 쏘고, 되돌아오는 데 걸린 시간으로 거리를 잽니다. 그러니 레이더가 바로 아는 것은 "어느 방향으로 얼마나 멀리"입니다. 이 두 수로 평면의 점을 나타내는 방법이 있을까요?
  2. 복원호도법에서 \(\pi = 180^\circ\)입니다. 반지름 \(r\)인 원 위에서 각 \(\theta\)인 점의 좌표는 \((r\cos\theta, r\sin\theta)\)입니다.
  3. 설명원점 O(극)와 O에서 오른쪽으로 그은 반직선(시초선)을 정하면, 점 P는 \(r = \overline{\mathrm{OP}}\)와 시초선에서 OP까지 잰 각 \(\theta\)로 정해집니다. \((r, \theta)\)를 점 P의 극좌표라고 합니다. 직교좌표와는 \[x = r\cos\theta,\quad y = r\sin\theta\]이고, 거꾸로 \(r^2 = x^2 + y^2\), \(\tan\theta = \frac{y}{x}\ (x \ne 0)\)입니다. 약속에 따라 \(r < 0\)이면 \(\theta\) 방향의 반대쪽으로 \(|r|\)만큼 간 점을 뜻합니다.
  4. 연결직교좌표에서는 한 점의 좌표가 하나뿐이지만, 극좌표에서는 \((r, \theta)\), \((r, \theta + 2\pi)\), \((-r, \theta + \pi)\)가 모두 같은 점입니다. 원, 장미, 나선처럼 극을 중심으로 도는 곡선은 극좌표로 쓰면 식이 아주 간단해집니다.
  5. 적용여섯 목표를 차례로 눌러 보세요. 뒤쪽 목표에는 음의 \(r\)이나 \(2\pi\)보다 큰 각이 나옵니다. 맞히면 직교좌표가 나타납니다. 직교좌표로 바꾼 값이 그림의 위치와 맞나요?
  6. 판단극 O 자체는 \(r = 0\)이기만 하면 \(\theta\)가 무엇이든 같은 점입니다. 그래서 극에서는 각이 정해지지 않습니다. 레이더 화면의 가운데에서 방향을 말할 수 없는 것과 같습니다.

2.1.2

\(\theta = \tan^{-1}\frac{y}{x}\)로 각을 구한 이 풀이, 맞을까?

극좌표와 직교좌표 · 오류 찾기

처음 틀린 줄을 누르세요. 틀린 곳이 없으면 마지막 줄을 누르세요. 초록은 문제, 주황은 풀이의 답입니다.

  1. 점 \((-1, -\sqrt{3})\)을 극좌표로 나타낸다. \(r = \sqrt{1 + 3} = 2\)이다.맞습니다.
  2. \(\tan\theta = \frac{-\sqrt{3}}{-1} = \sqrt{3}\)이므로 \(\theta = \frac{\pi}{3}\)이다.여기가 틀렸습니다. \(\tan\theta = \sqrt{3}\)인 각은 \(\frac{\pi}{3}\)과 \(\frac{4\pi}{3}\) 두 가지입니다. 점이 제3사분면에 있으므로 \(\theta = \frac{4\pi}{3}\)입니다. \(\tan^{-1}\)은 언제나 \(-\frac{\pi}{2}\)와 \(\frac{\pi}{2}\) 사이의 값만 줍니다.
  3. 따라서 극좌표는 \(\left(2, \frac{\pi}{3}\right)\)이다.앞 줄을 이어받았습니다. 이 점은 \((1, \sqrt{3})\)으로, 원래 점의 반대쪽입니다.
  4. 이 풀이에는 틀린 곳이 없다.그림에서 두 점의 위치를 비교하세요.
  1. 점 \((0, -2)\)를 극좌표로 나타낸다. \(r = 2\)이다.맞습니다.
  2. \(\tan\theta = \frac{-2}{0}\)은 정의되지 않으므로 이 점은 극좌표로 나타낼 수 없다.여기가 틀렸습니다. \(\tan\theta = \frac{y}{x}\)는 \(x \ne 0\)일 때만 쓰는 식일 뿐입니다. 점은 \(y\)축의 음의 부분에 있으므로 \(\theta = \frac{3\pi}{2}\), 극좌표는 \(\left(2, \frac{3\pi}{2}\right)\)입니다.
  3. 그러므로 \(y\)축 위의 점은 직교좌표로만 나타낸다.앞 줄을 이어받은 결론입니다.
  4. 이 풀이에는 틀린 곳이 없다.\(\cos\theta = 0\), \(\sin\theta = -1\)인 각을 생각하세요.
  1. 극좌표 \(\left(-2, \frac{4\pi}{3}\right)\)인 점을 직교좌표로 바꾼다.문제를 옮겼습니다.
  2. \(x = -2\cos\frac{4\pi}{3} = -2 \cdot \left(-\frac{1}{2}\right) = 1\)이다.맞습니다.
  3. \(y = -2\sin\frac{4\pi}{3} = -2 \cdot \left(-\frac{\sqrt{3}}{2}\right) = \sqrt{3}\)이므로 점은 \((1, \sqrt{3})\)이다.맞습니다. 음의 \(r\)이어도 \(x = r\cos\theta\), \(y = r\sin\theta\)를 그대로 씁니다.
  4. 이 풀이에는 틀린 곳이 없다.맞습니다. \(\left(-2, \frac{4\pi}{3}\right)\)과 \(\left(2, \frac{\pi}{3}\right)\)은 같은 점입니다.
  1. 극방정식 \(r = 2\cos\theta\)를 직교좌표의 방정식으로 바꾼다.문제를 옮겼습니다.
  2. \(r = \sqrt{x^2 + y^2}\), \(\cos\theta = x\)이므로 \(\sqrt{x^2 + y^2} = 2x\)이다.여기가 틀렸습니다. \(\cos\theta = \frac{x}{r}\)입니다. 양변에 \(r\)을 곱해 \(r^2 = 2r\cos\theta\), 곧 \(x^2 + y^2 = 2x\)로 바꾸어야 합니다.
  3. 제곱하여 정리하면 \(y^2 = 3x^2\ (x \ge 0)\), 곧 두 반직선이다.앞 줄을 이어받았습니다. 바른 답 \((x - 1)^2 + y^2 = 1\)은 원입니다.
  4. 이 풀이에는 틀린 곳이 없다.그림의 곡선이 반직선처럼 보이나요?
  1. 질문직교좌표를 극좌표로 바꿀 때 \(r = \sqrt{x^2 + y^2}\), \(\theta = \tan^{-1}\frac{y}{x}\)로 계산하면 될까요? 계산기도 이렇게 하라고 알려 주는 것 같습니다.
  2. 복원\(x = r\cos\theta\), \(y = r\sin\theta\), \(r^2 = x^2 + y^2\). \(\tan\theta\)는 주기가 \(\pi\)인 함수라, 같은 \(\tan\) 값을 갖는 각이 \(0 \le \theta < 2\pi\)에 두 개 있습니다.
  3. 설명\(\tan\theta = \frac{y}{x}\)는 각의 후보를 두 개로 좁혀 줄 뿐입니다. 점이 몇 사분면에 있는지 보고 하나를 골라야 합니다(풀이 1). \(x = 0\)이면 이 식을 쓸 수 없지만 각은 \(\frac{\pi}{2}\)나 \(\frac{3\pi}{2}\)로 정해집니다(풀이 2). 극방정식을 직교좌표로 바꿀 때는 \(\cos\theta = \frac{x}{r}\)이므로 양변에 \(r\)을 곱해 \(r\cos\theta\) 꼴을 만드는 것이 요령입니다(풀이 4).
  4. 연결프로그래밍 언어의 \(\operatorname{atan2}(y, x)\) 함수는 \(x\), \(y\)의 부호를 함께 보고 사분면까지 맞는 각을 돌려줍니다. \(\tan^{-1}\frac{y}{x}\)가 사분면을 잃어버리는 문제를 해결하려고 만든 함수입니다.
  5. 적용네 풀이에서 처음 틀린 줄을 찾으세요. 풀이 1의 답은 원래 점과 어떤 관계인가요? 풀이 3에서 음의 \(r\)이 나왔는데도 맞는 까닭은 무엇인가요?
  6. 판단극방정식 양변에 \(r\)을 곱하면 극(\(r = 0\))이 새 해로 끼어들 수 있습니다. \(r = 2\cos\theta\)는 이미 \(\theta = \frac{\pi}{2}\)에서 극을 지나므로 괜찮지만, 다른 식에서는 극이 원래 곡선 위에 있는지 따로 확인해야 합니다.
