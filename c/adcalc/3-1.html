단조수렴정리

3.1.1

계속 커지는데 어떤 수도 넘지 못하는 수열은 어디로 갈까?

단조수렴정리 · 조작 · 발견
천장 \(M\)
—
\(n = 10^4\)인 항
—
천장을 넘는 항
—

천장 선을 위아래로 끌어, 어떤 항도 넘지 못하는 가장 낮은 천장을 찾아보세요. 가로축은 \(n = 1\)부터 \(10^4\)까지 로그 눈금입니다.

  1. 질문수열 \(\sqrt{2},\ \sqrt{2 + \sqrt{2}},\ \sqrt{2 + \sqrt{2 + \sqrt{2}}},\ \cdots\)은 계속 커지지만 2를 넘지 못합니다. 그렇다면 이 수열은 반드시 어떤 수에 수렴할까요? 극한값을 모르는데도 수렴한다고 말할 수 있을까요?
  2. 복원모든 \(n\)에 대해 \(a_n \le a_{n+1}\)이면 증가수열, \(a_n \le M\)인 \(M\)이 있으면 위로 유계라고 합니다. 수렴하는 수열은 유계이지만, 유계인 수열이 모두 수렴하지는 않습니다(\((-1)^n\)).
  3. 설명단조수렴정리: 증가하면서 위로 유계인 수열은 수렴한다. 감소하면서 아래로 유계인 수열도 수렴합니다. 증가수열은 진동할 수 없으므로, 넘지 못하는 천장이 있으면 천장 가운데 가장 낮은 것(상한)으로 모여들 수밖에 없습니다. 이 정리의 힘은 극한값을 몰라도 수렴을 보장해 준다는 데 있습니다. \(\left(1 + \frac{1}{n}\right)^n\)은 증가하고 3보다 작으므로 수렴하고, 그 극한을 \(e\)라고 이름 붙였습니다.
  4. 연결이 정리는 실수에 "빈틈이 없다"는 성질(완비성)에 기대고 있습니다. 유리수만 있는 세상에서는 \(1,\ 1.4,\ 1.41,\ 1.414,\ \cdots\)처럼 증가하고 2를 넘지 않는 유리수 수열이 \(\sqrt{2}\)라는 "구멍"으로 가므로 수렴하지 못합니다. 다음 절의 양항급수 판정법은 모두 이 정리에서 출발합니다. 양항급수의 부분합은 증가수열이기 때문입니다.
  5. 적용보기마다 천장을 내려 보며, 어떤 항도 넘지 못하는 가장 낮은 천장을 찾으세요. \(\sum\frac{1}{k^2}\)의 천장은 약 1.645(\(\frac{\pi^2}{6}\))입니다. \(\sum\frac{1}{k}\)에는 그런 천장이 있나요? 그림의 범위에서는 막힌 것처럼 보이지만 \(n\)을 더 늘리면 어떻게 될까요?
  6. 판단천장이 있다고 그 천장이 극한값인 것은 아닙니다. \(\sqrt{2 + a_n}\)은 3보다도 작지만 극한은 2입니다. 또 \(n = 10^4\)까지 천장을 넘지 않았다는 것은 증명이 아닙니다. \(\sum\frac{1}{k}\)은 \(n = 10^4\)에서 약 9.79이지만 결국 어떤 수든 넘어섭니다.

3.1.2

극한을 \(L\)로 놓고 방정식을 풀면 끝일까?

단조수렴정리 · 증명 조립
  1. \(a_1 = \sqrt{2} < 2\)이고, \(a_n < 2\)이면 \(a_{n+1} = \sqrt{2 + a_n} < \sqrt{4} = 2\)이다. 수학적 귀납법으로 모든 \(n\)에 대해 \(0 < a_n < 2\)이다.
  2. \(a_{n+1}^2 - a_n^2 = 2 + a_n - a_n^2 = (2 - a_n)(1 + a_n) > 0\)이므로 \(a_{n+1} > a_n\), 곧 증가수열이다.이 부등식에는 \(a_n < 2\)라는 사실이 쓰입니다. 먼저 보여야 합니다.
  3. 증가하고 위로 유계이므로 단조수렴정리에 따라 극한 \(L = \lim a_n\)이 존재한다.증가와 유계를 모두 보인 뒤에야 단조수렴정리를 쓸 수 있습니다.
  4. \(a_{n+1} = \sqrt{2 + a_n}\)의 양변에 극한을 취하면 \(L = \sqrt{2 + L}\), 곧 \(L^2 - L - 2 = 0\)이다.극한이 존재한다는 것을 보이기 전에는 극한을 \(L\)로 놓을 수 없습니다. 아래의 함정 수열을 보세요.
  5. \(L \ge 0\)이므로 \(L = 2\)이다.방정식 \(L^2 - L - 2 = 0\)이 먼저 나와야 합니다.
  6. 모든 항이 3보다 작으므로 극한값은 3이다.위로 막는 수는 극한값이 아닙니다. 2도, 3도, 100도 천장이 됩니다.

함정 수열 \(b_{n+1} = 2b_n\)도 극한을 \(L\)로 놓으면 \(L = 2L\)에서 \(L = 0\)이 나옵니다. 그러나 이 수열은 1, 2, 4, 8, …로 발산합니다.

  1. 질문\(a_{n+1} = \sqrt{2 + a_n}\)의 극한을 \(L\)이라 하면 \(L = \sqrt{2 + L}\)에서 \(L = 2\)가 바로 나옵니다. 이것으로 증명이 끝난 걸까요?
  2. 복원단조수렴정리: 증가하면서 위로 유계인 수열은 수렴합니다. 수학적 귀납법은 첫 경우와 "\(n\)일 때 성립하면 \(n + 1\)일 때도 성립"을 보이는 방법입니다.
  3. 설명"극한을 \(L\)로 놓는다"는 것은 극한이 있다고 가정하는 것입니다. 함정 수열 \(b_{n+1} = 2b_n\)도 같은 방법으로 \(L = 0\)이 나오지만 실제로는 발산합니다. 그래서 순서가 중요합니다. ① 유계임을 보인다(귀납법). ② 증가함을 보인다. ③ 단조수렴정리로 극한이 존재함을 안다. ④ 그다음에야 점화식에 극한을 취해 값을 구한다.
  4. 연결그림의 거미줄은 \(y = \sqrt{2 + x}\)와 \(y = x\) 사이를 오가며 그립니다. 계단이 교점 \((2, 2)\)으로 올라가는 모습이 "증가하고 2에 막힌다"를 보여 줍니다. 뉴턴의 방법도 \(x_{n+1} = g(x_n)\) 꼴의 점화식이고, 같은 방법으로 수렴을 증명할 수 있습니다.
  5. 적용단계를 순서대로 쌓아 증명을 완성하세요. 함정 수열로 바꾸어 거미줄이 어디로 가는지 보세요. \(y = 2x\)와 \(y = x\)의 교점 0으로 가나요?
  6. 판단"\(L = g(L)\)의 해"는 수렴한다면 갈 수 있는 후보일 뿐입니다. 후보가 여러 개일 때 어느 것으로 가는지, 그리고 정말 수렴하는지는 따로 보여야 합니다.
