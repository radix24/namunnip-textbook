문학과 수학

문학 작품에도 수학이 숨어 있습니다. 시조의 음수율처럼 글자 수의 규칙이 형식을 만들고, 소설은 상상하기 어려운 큰 수를 다루기도 합니다. 이 절에서는 피보나치 수열로 시를 짓고, 상용로그로 소설 속 도서관의 크기를 가늠합니다.

1.3.1

줄마다 글자 수가 1, 1, 2, 3, 5, 8인 시를 지어 볼까?

수열과 문학 · 만들기

  1. 질문시조는 3·4·3·4처럼 글자 수의 규칙을 지킵니다. 행마다 글자 수가 피보나치 수열을 따르는 시(피보나치 시)를 지으면, 시의 모양은 어떻게 될까요?
  2. 복원피보나치 수열은 \(F_1 = F_2 = 1\), \(F_{n+2} = F_{n+1} + F_n\)입니다.
  3. 설명피보나치 시는 행의 글자 수가 1, 1, 2, 3, 5, 8, …로 늘어납니다. 각 행이 앞의 두 행을 합친 길이라서, 시는 점점 빠르게 넓어지는 삼각형 모양이 됩니다. 수학의 규칙이 형식을 정하고, 그 형식 안에서 표현을 고르는 것이 창작의 재미입니다. 음악의 박자, 시조의 음수율도 같은 생각입니다.
  4. 연결정해진 규칙(제약) 안에서 만드는 창작은 문학 실험 모임 울리포(OuLiPo)가 즐겨 쓴 방법입니다.
  5. 적용예시 시를 바꿔 여러분의 피보나치 시를 6행 이상 지어 보세요. 7행은 몇 글자여야 하나요?
  6. 판단글자 수를 맞추려고 뜻이 어색한 말을 넣으면 시가 망가집니다. 규칙과 의미가 둘 다 살아야 좋은 작품입니다.

1.3.2

세상의 모든 책이 있는 도서관에는 책이 몇 권 있을까?

거듭제곱과 상용로그 · 예측→확인

보르헤스의 소설 「바벨의 도서관」에는 410쪽, 쪽마다 40행, 행마다 80글자, 25가지 기호로 만들 수 있는 모든 책이 있습니다. 예측: 책의 수는 우주의 원자 수(약 \(10^{80}\))와 비교하면?

  1. 질문가능한 모든 글자 배열을 다 모은 도서관이라면 책이 너무 많아 셀 수도 없을 것 같습니다. 직접 쓸 수 없을 만큼 큰 수의 크기는 어떻게 가늠할까요?
  2. 복원\(\log_{10} a^n = n \log_{10} a\). 양의 정수 \(N\)의 자릿수는 \(\lfloor \log_{10} N \rfloor + 1\)입니다.
  3. 설명한 권의 글자 수는 \(410 \times 40 \times 80 = 1\,312\,000\)이고 자리마다 25가지 기호가 올 수 있으므로 책의 수는 \(25^{1\,312\,000}\)입니다. \(\log_{10} 25 \approx 1.39794\)이므로 \(\log_{10} 25^{1\,312\,000} \approx 1\,834\,097.3\), 곧 이 수는 약 183만 자리의 수입니다. 80자리인 우주의 원자 수와는 비교할 수도 없습니다. 상용로그는 이런 수의 "자릿수"를 계산해 크기를 가늠하게 해 줍니다.
  4. 연결비밀번호의 경우의 수, 암호의 열쇠 공간도 같은 방식으로 계산합니다. 글자 종류보다 길이가 경우의 수를 훨씬 크게 늘립니다.
  5. 적용기호의 수와 글자 수를 바꾸며 자릿수가 어떻게 변하는지 보세요. 글자 수를 2배로 하면 자릿수는 몇 배가 되나요?
  6. 판단모든 책이 있다는 것은 의미 있는 책을 찾을 수 있다는 뜻이 아닙니다. 거의 모든 책은 무의미한 기호의 나열이라 원하는 책을 찾는 일은 사실상 불가능합니다.
