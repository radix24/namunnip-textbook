정규직교기저

기저 벡터들이 서로 수직이고 크기가 모두 1이면 좌표를 구하기가 아주 쉬워집니다. 연립방정식을 풀 필요 없이 내적 한 번이면 됩니다. 이런 기저를 정규직교기저라고 하고, 아무 기저에서나 정사영을 빼 나가며 정규직교기저를 만드는 방법이 그람-슈미트 과정입니다. 이 절에서는 3차원에서 이 과정을 한 단계씩 실행하고, 두 기저에서 좌표를 구하는 수고를 비교합니다.

1.8.1

비스듬한 두 벡터로 직각 자를 만들 수 있을까?

그람-슈미트 과정 · 조작

점선 원은 반지름 1인 원입니다. 끝점은 0.5 간격으로 맞춰집니다.

  1. 질문기저가 서로 수직이고 길이가 1이면 좌표를 구할 때 연립방정식이 필요 없습니다(다음 카드). 그런데 처음 주어진 기저는 대개 비스듬합니다. 생성하는 공간은 그대로 두고 기저만 반듯하게 고칠 수 있을까요?
  2. 복원\(\vec{v}\)의 \(\vec{u}\) 방향 정사영을 빼면 \(\vec{u}\)와 수직인 부분이 남습니다. 단위벡터 \(\vec{u}\)이면 정사영은 \((\vec{v}\cdot\vec{u})\vec{u}\)입니다.
  3. 설명서로 수직이고 길이가 1인 벡터로 이루어진 기저를 정규직교기저라고 합니다. 그람-슈미트 과정은 일차독립인 \(\vec{v}_1, \vec{v}_2, \ldots\)에서 차례로 만듭니다. ① \(\vec{u}_1 = \vec{v}_1 / |\vec{v}_1|\). ② \(\vec{w}_2 = \vec{v}_2 - (\vec{v}_2\cdot\vec{u}_1)\vec{u}_1\)(앞 방향의 그림자 빼기). ③ \(\vec{u}_2 = \vec{w}_2 / |\vec{w}_2|\). 셋째부터는 앞의 모든 \(\vec{u}\) 방향 그림자를 빼고 길이를 1로 맞춥니다. 매 단계에서 생성하는 공간은 바뀌지 않습니다.
  4. 연결컴퓨터는 이 과정을 행렬 분해(QR 분해)로 바꾸어 최소제곱 문제를 안정적으로 풉니다. 3D 그래픽에서 카메라의 앞·위·옆 방향을 서로 수직으로 다시 맞출 때도 씁니다.
  5. 적용단계 버튼을 차례로 누르며 각 단계에서 무엇이 생기는지 보세요. 그다음 \(\vec{v}_1\)을 움직이면 \(\vec{u}_1\), \(\vec{u}_2\)가 어떻게 바뀌나요? 순서를 바꾸어(\(\vec{v}_2\)부터) 시작하면 결과가 같을까요?
  6. 판단\(\vec{v}_1\)과 \(\vec{v}_2\)가 평행하면 ②에서 \(\vec{w}_2 = \vec{0}\)이 되어 ③에서 0으로 나누게 됩니다. 그람-슈미트 과정은 일차독립인 벡터에만 쓸 수 있고, 거의 평행하면 계산 오차가 커집니다.

1.8.2

정규직교기저의 좌표는 왜 내적 한 번이면 될까?

정규직교기저와 좌표 · 만들기

—

  1. 질문소리나 사진은 수를 늘어놓은 긴 벡터입니다. 이것을 "평평한 정도, 왼쪽-오른쪽 차이, …" 같은 기본 모양의 합으로 나누면 압축이 쉬워집니다. 기본 모양마다 얼마씩 섞였는지 가장 빨리 알아내는 방법은 무엇일까요?
  2. 복원보통의 기저에서는 좌표를 구하려고 연립방정식을 풀어야 했습니다(기저와 좌표 카드). 그람-슈미트 과정으로 기저를 정규직교기저로 바꿀 수 있었습니다.
  3. 설명\(\{\vec{u}_1, \ldots, \vec{u}_n\}\)이 정규직교기저이고 \(\vec{x} = c_1\vec{u}_1 + \cdots + c_n\vec{u}_n\)이면, 양변에 \(\vec{u}_k\)를 내적할 때 \(\vec{u}_k\cdot\vec{u}_j\)가 \(j \ne k\)이면 0, \(j = k\)이면 1이므로 \(c_k = \vec{x}\cdot\vec{u}_k\)만 남습니다. 좌표 하나에 내적 한 번입니다. 또 \(|\vec{x}|^2 = c_1^2 + \cdots + c_n^2\)이 성립합니다. 이 카드의 기저는 성분이 \(\pm\frac{1}{2}\)인 네 벡터 \(\vec{u}_1 = \frac{1}{2}(1,1,1,1)\), \(\vec{u}_2 = \frac{1}{2}(1,1,-1,-1)\), \(\vec{u}_3 = \frac{1}{2}(1,-1,1,-1)\), \(\vec{u}_4 = \frac{1}{2}(1,-1,-1,1)\)입니다.
  4. 연결JPEG 사진과 MP3 음악은 이와 같은 정규직교기저(코사인 모양)로 좌표를 구한 뒤, 작은 좌표를 버려 용량을 줄입니다. \(|\vec{x}|^2 = \sum c_k^2\)이므로 작은 \(c_k\)를 버려도 잃는 양이 \(c_k^2\)만큼으로 작습니다.
  5. 적용먼저 슬라이더로 목표 신호를 만들어 보세요. 그다음 \(c_1 = \vec{x}\cdot\vec{u}_1\)을 손으로 계산해 맞는지 확인하세요. "가장 작은 계수 버리기"를 누르면 신호가 얼마나 달라지나요?
  6. 판단\(c_k = \vec{x}\cdot\vec{u}_k\)는 기저가 정규직교일 때만 맞습니다. 수직이기만 하고 길이가 1이 아니면 \(c_k = \dfrac{\vec{x}\cdot\vec{u}_k}{\vec{u}_k\cdot\vec{u}_k}\)로 나누어야 하고, 수직이 아니면 연립방정식을 풀어야 합니다.
