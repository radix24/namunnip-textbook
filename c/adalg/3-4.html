직교행렬과 직교대각화

열벡터들이 정규직교기저를 이루는 행렬을 직교행렬이라고 합니다. 회전과 대칭이 그 예이며, 역행렬이 전치행렬과 같습니다. 대칭행렬은 고유벡터끼리 서로 수직이라 직교행렬로 대각화할 수 있습니다. 이 절에서는 대칭행렬이 원을 타원으로 바꿀 때 타원의 축이 고유벡터 방향임을 확인하고, 고유벡터가 수직인 이유를 한 단계씩 증명합니다.

3.4.1

대칭행렬은 원을 어떤 모양으로 바꿀까?

직교행렬과 직교대각화 · 조작

  1. 질문\(A = \begin{pmatrix} a & b \\ b & d \end{pmatrix}\)처럼 대각선에 대해 대칭인 행렬로 단위원을 변환하면 어떤 곡선이 될까요? 그 곡선의 축은 어떤 방향일까요?
  2. 복원열벡터들이 정규직교기저를 이루는 행렬 \(Q\)를 직교행렬이라고 하며, \(Q^TQ = I\), 곧 \(Q^{-1} = Q^T\)입니다. 회전과 대칭이 직교행렬입니다.
  3. 설명대칭행렬(\(A^T = A\))은 고윳값이 모두 실수이고, 서로 다른 고윳값의 고유벡터는 서로 수직입니다(다음 카드에서 증명). 그래서 단위 고유벡터를 열로 하는 직교행렬 \(Q\)로 \(A = QDQ^T\)라 쓸 수 있고, 이것을 직교대각화라고 합니다. 그림으로는 "\(Q^T\)로 돌리고, 축마다 \(\lambda\)배 늘이고, \(Q\)로 되돌리기"이므로, 단위원은 축이 고유벡터 방향이고 반지름이 \(|\lambda_1|\), \(|\lambda_2|\)인 타원이 됩니다.
  4. 연결재료가 받는 힘(응력), 자료의 퍼진 정도(공분산 행렬)가 모두 대칭행렬입니다. 공분산 행렬의 고유벡터 방향을 찾는 것이 자료 분석의 주성분 분석이고, 다음 절에서는 이차곡선의 축을 찾는 데 씁니다.
  5. 적용원 위의 점 \(\vec{x}\)를 끌어 \(A\vec{x}\)가 \(\vec{x}\)와 같은 방향이 되는 곳을 찾으세요. 그곳이 타원의 가장 긴 곳, 가장 짧은 곳과 일치하나요? \(b\)를 바꿔도 두 고유벡터는 늘 수직인가요? 고윳값 하나를 음수로 만들면 어떻게 되나요?
  6. 판단대칭이 아닌 행렬도 원을 타원으로 바꾸지만, 그 타원의 축이 고유벡터 방향과 일치하지 않고 고유벡터끼리 수직이 아닐 수 있습니다. "고유벡터가 수직"은 대칭행렬의 특별한 성질입니다.

3.4.2

대칭행렬의 고유벡터는 왜 서로 수직일까?

대칭행렬의 성질 · 증명 조립

  1. \(A^T = A\)이고 \(A\vec{v}_1 = \lambda_1\vec{v}_1\), \(A\vec{v}_2 = \lambda_2\vec{v}_2\), \(\lambda_1 \ne \lambda_2\)라 하자.
  2. \(\lambda_1(\vec{v}_1\cdot\vec{v}_2) = (\lambda_1\vec{v}_1)\cdot\vec{v}_2 = (A\vec{v}_1)\cdot\vec{v}_2\)이다.먼저 무엇을 가정하는지 밝혀야 합니다.
  3. \((A\vec{v}_1)\cdot\vec{v}_2 = (A\vec{v}_1)^T\vec{v}_2 = \vec{v}_1^TA^T\vec{v}_2 = \vec{v}_1^TA\vec{v}_2\) (\(A^T = A\)를 씀)이다.이 식은 \(\lambda_1(\vec{v}_1\cdot\vec{v}_2)\)를 행렬로 바꾼 뒤에 이어집니다.
  4. \(\vec{v}_1^TA\vec{v}_2 = \vec{v}_1\cdot(A\vec{v}_2) = \lambda_2(\vec{v}_1\cdot\vec{v}_2)\)이다.\(A\)를 \(\vec{v}_2\) 쪽으로 옮기는 단계(대칭을 쓰는 곳)가 먼저입니다.
  5. 따라서 \((\lambda_1 - \lambda_2)(\vec{v}_1\cdot\vec{v}_2) = 0\)이고 \(\lambda_1 \ne \lambda_2\)이므로 \(\vec{v}_1\cdot\vec{v}_2 = 0\), 곧 두 고유벡터는 수직이다.같은 양을 두 가지로 나타낸 식이 아직 완성되지 않았습니다.
  6. \(\lambda_1 \ne \lambda_2\)이면 \(\vec{v}_1 \ne \vec{v}_2\)이므로 두 벡터는 수직이다.다른 벡터라고 수직인 것은 아닙니다. 대칭이 아닌 행렬(c ≠ 1)에서 그림을 보세요.
  1. 질문앞 카드에서 대칭행렬의 두 고유벡터는 \(b\)를 아무리 바꿔도 늘 수직이었습니다. 우연일까요, 아니면 증명할 수 있을까요?
  2. 복원\(\vec{u}\cdot\vec{v} = \vec{u}^T\vec{v}\), \((AB)^T = B^TA^T\)입니다.
  3. 설명핵심은 \((A\vec{v}_1)\cdot\vec{v}_2\)를 두 가지로 계산하는 것입니다. 한 번은 \(A\vec{v}_1 = \lambda_1\vec{v}_1\)으로, 한 번은 \(A\)를 반대편으로 옮겨 \(A\vec{v}_2 = \lambda_2\vec{v}_2\)로 계산합니다. \(A\)를 옮길 때 \(A^T\)가 생기는데, 대칭이라 \(A^T = A\)입니다. 두 결과가 같으려면 \(\lambda_1 \ne \lambda_2\)일 때 내적이 0이어야 합니다.
  4. 연결이 성질에 "대칭행렬의 고윳값은 실수"라는 사실까지 쓰면, 모든 실대칭행렬은 직교대각화된다는 스펙트럼 정리가 나옵니다. 다음 절에서 이차곡선의 축을 찾는 근거입니다.
  5. 적용증명을 순서대로 쌓으세요. 그다음 \(c\)를 움직여 대칭(\(c = 1\))일 때만 두 고유벡터가 수직인지 확인하세요.
  6. 판단증명에서 \(A^T = A\)를 쓴 곳은 한 군데뿐입니다. 그곳이 없으면 증명이 무너지고, 그림에서도 \(c \ne 1\)이면 각이 90°가 아닙니다. 가정이 증명의 어디에 쓰였는지 찾는 습관이 중요합니다.
