이차곡선의 표준형

\(ax^2 + 2bxy + cy^2 = k\)는 대칭행렬 하나로 \(\vec{x}^TA\vec{x} = k\)라 쓸 수 있습니다. \(A\)를 직교대각화해 좌표축을 고유벡터 방향으로 돌리면 \(xy\)항이 사라지고 익숙한 표준형이 나타납니다. 이 절에서는 축을 천천히 돌리며 곡선이 반듯해지는 것을 보고, 고윳값의 부호만으로 타원과 쌍곡선을 가려냅니다.

3.5.1

xy항이 있는 이차곡선은 어떻게 표준형으로 바꿀까?

이차형식과 축의 회전 · 조작

—

  1. 질문\(5x^2 - 4xy + 8y^2 = 36\)은 타원일까요, 쌍곡선일까요? \(xy\)항 때문에 표준형으로 바로 읽을 수 없습니다. 좌표축을 얼마나 돌리면 \(xy\)항이 사라질까요?
  2. 복원대칭행렬은 \(A = QDQ^T\)로 직교대각화되고, \(Q\)는 회전(또는 대칭)입니다.
  3. 설명\(ax^2 + 2bxy + cy^2 = \vec{x}^TA\vec{x}\), \(A = \begin{pmatrix} a & b \\ b & c \end{pmatrix}\)로 씁니다(이차형식). 새 좌표 \(\vec{X} = Q^T\vec{x}\)를 쓰면 \(\vec{x}^TA\vec{x} = \vec{X}^TD\vec{X} = \lambda_1X^2 + \lambda_2Y^2\)이 되어 \(XY\)항이 사라집니다. 새 축은 \(A\)의 고유벡터 방향이고, 고윳값의 부호로 모양이 정해집니다: 둘 다 양수이면 타원, 부호가 다르면 쌍곡선입니다.
  4. 연결회전한 각 \(\theta\)는 \(\tan2\theta = \dfrac{2b}{a - c}\)로도 구할 수 있습니다. 3차원에서는 같은 방법으로 \(x^2 + y^2 + z^2 + 2xy + \cdots\) 꼴의 이차곡면을 타원면, 쌍곡면으로 분류합니다.
  5. 적용"좌표축 돌리기"를 100%까지 움직이며 곡선이 새 축에 대해 반듯해지는 것을 보세요. 표준형의 계수가 고윳값과 같은지 확인하세요. \(a\), \(c\)를 작게 하고 \(b\)를 키우면 모양이 타원에서 쌍곡선으로 바뀌는 순간이 있나요? 그때 \(\det A = ac - b^2\)은 얼마인가요?
  6. 판단곡선은 그대로이고 좌표축만 돌린 것입니다. 표준형에서 읽은 꼭짓점과 초점은 새 좌표 \((X, Y)\)의 값이므로, 원래 좌표로 돌려놓으려면 \(\vec{x} = Q\vec{X}\)를 계산해야 합니다.

3.5.2

그리지 않고 이차곡선의 모양을 알 수 있을까?

고윳값으로 분류하기 · 예측→확인

—

  1. 질문\(x^2 + 4xy + y^2 = 3\)은 \(x^2\)과 \(y^2\)의 계수가 모두 양수라 타원처럼 보입니다. 정말 그럴까요? 계산 몇 번으로 모양을 알아낼 수 있을까요?
  2. 복원\(ax^2 + 2bxy + cy^2 = k\)는 축을 돌려 \(\lambda_1X^2 + \lambda_2Y^2 = k\)로 바꿀 수 있고, \(\lambda_1, \lambda_2\)는 \(A = \begin{pmatrix} a & b \\ b & c \end{pmatrix}\)의 고윳값입니다.
  3. 설명\(k > 0\)일 때 ① \(\lambda_1, \lambda_2\)가 모두 양수이면 타원, ② 부호가 다르면 쌍곡선, ③ 하나가 0이고 하나가 양수이면 평행한 두 직선, ④ 모두 0 이하이면 그래프가 없습니다. 고윳값을 다 구하지 않아도 \(\det A = \lambda_1\lambda_2\), \(\mathrm{tr}\,A = \lambda_1 + \lambda_2\)로 부호를 알 수 있습니다: \(\det A > 0\)이고 \(\mathrm{tr}\,A > 0\)이면 타원, \(\det A < 0\)이면 쌍곡선입니다.
  4. 연결이 판정은 다변수 함수의 극대·극소 판정(헤세 행렬), 구조물이 안정한지 판정하는 데도 같은 모양으로 나옵니다. 모두 "대칭행렬의 고윳값 부호"를 봅니다.
  5. 적용여섯 식의 모양을 먼저 고르고 확인하세요. 확인할 때마다 \(\det A\)와 \(\mathrm{tr}\,A\)만으로도 같은 답이 나오는지 따져 보세요.
  6. 판단\(x^2\)과 \(y^2\)의 계수만 보고 판단하면 \(xy\)항의 효과를 놓칩니다. 또 우변 \(k\)의 부호도 봐야 합니다. \(k < 0\)이면 양변에 \(-1\)을 곱해 생각합니다.
