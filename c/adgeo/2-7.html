단위속력곡선으로 재매개화

정칙곡선은 호의 길이 함수 \(s(t)\)가 증가함수이므로 역함수를 이용해 언제나 단위속력곡선으로 재매개화할 수 있습니다. 곡선의 모양은 그대로이고 "시간표"만 바뀝니다. 이 절에서는 나선의 매개변수를 조절해 속력이 1이 되게 만들고, 재매개화 풀이에서 흔한 실수를 찾아봅니다.

2.7.1

나선 위를 속력 1로 움직이게 하려면 매개변수를 어떻게 바꿀까?

단위속력곡선으로 재매개화 · 만들기

점은 s = 0, 1, 2, …인 곳이고 주황 큰 점은 5마다 찍었습니다. 그림의 높이 방향은 보기 좋게 절반으로 줄였습니다.

  1. 질문나선 \(\vec{r}(t) = (a\cos t, a\sin t, bt)\)의 속력은 \(\sqrt{a^2 + b^2}\)로 일정하지만 1은 아닙니다. 매개변수를 \(t = \frac{s}{c}\)로 바꾸면 속력이 1이 되게 할 수 있을까요? \(c\)는 얼마여야 할까요?
  2. 복원연쇄법칙: \(\frac{d\vec{r}}{ds} = \frac{d\vec{r}}{dt}\cdot\frac{dt}{ds}\)입니다.
  3. 설명정칙곡선 \(\vec{r}(t)\)의 호의 길이 함수 \(s(t) = \int_{t_0}^{t}|\vec{r}\,'(u)|\,du\)는 증가함수이므로 역함수 \(t = t(s)\)가 있고, \(\vec{r}(t(s))\)는 \(\left|\frac{d\vec{r}}{ds}\right| = \frac{|\vec{r}\,'(t)|}{ds/dt} = 1\)인 단위속력곡선이 됩니다. 이것을 단위속력곡선으로 재매개화한다고 합니다. 나선은 \(s = \sqrt{a^2 + b^2}\,t\)이므로 \(c = \sqrt{a^2 + b^2}\)이고, \(\vec{r}(s) = \left(a\cos\frac{s}{c}, a\sin\frac{s}{c}, \frac{bs}{c}\right)\)입니다.
  4. 연결속력이 일정하지 않은 곡선은 \(s(t)\)의 역함수를 식으로 구하기 어려울 때가 많아, 앞 카드처럼 수치로 구합니다. 다음 절의 곡률은 단위속력곡선에서 \(\kappa = \left|\frac{d^2\vec{r}}{ds^2}\right|\)로 간단히 정의됩니다.
  5. 적용\(c\)를 조절해 \(s\)를 1씩 늘린 점 사이의 곡선 거리가 1이 되게 하세요. \(a\), \(b\)를 바꾸면 필요한 \(c\)는 어떻게 바뀌나요? 식 \(\sqrt{a^2 + b^2}\)과 비교하세요.
  6. 판단재매개화는 곡선(그림)을 바꾸지 않고 "시간표"만 바꿉니다. \(c\)를 아무 값으로 해도 같은 나선이 그려지지만, 단위속력이 되는 \(c\)는 하나뿐입니다. 또 \(s\)의 시작점을 어디로 잡느냐에 따라 식이 평행이동만큼 달라질 수 있습니다.

2.7.2

이 재매개화 풀이는 어디서 틀렸을까?

재매개화의 계산 · 오류 찾기

처음 틀린 줄을 누르세요. 틀린 곳이 없으면 마지막 줄을 누르세요.

  1. \(\vec{r}(t) = (3\cos t, 3\sin t, 4t)\), \(t \ge 0\)을 단위속력곡선으로 재매개화한다.문제입니다.
  2. \(\vec{r}\,'(t) = (-3\sin t, 3\cos t, 4)\)이므로 \(|\vec{r}\,'(t)| = 3 + 4 = 7\)이다.여기가 틀렸습니다. 크기는 \(\sqrt{9\sin^2t + 9\cos^2t + 16} = 5\)입니다.
  3. \(s = 7t\)이므로 \(t = \frac{s}{7}\), \(\vec{r}(s) = \left(3\cos\frac{s}{7}, 3\sin\frac{s}{7}, \frac{4s}{7}\right)\)이다.앞 줄의 잘못을 이어받았습니다. 바르게는 \(t = \frac{s}{5}\)입니다.
  4. 틀린 곳이 없다.마지막 식의 속력을 직접 계산해 보세요.
  1. \(\vec{r}(t) = (e^t\cos t, e^t\sin t)\), \(t \ge 0\)을 \(t = 0\)에서부터 잰 호의 길이로 재매개화한다.문제입니다.
  2. \(|\vec{r}\,'(t)| = \sqrt{2}\,e^t\)이다.맞습니다. \(\vec{r}\,' = e^t(\cos t - \sin t, \sin t + \cos t)\)의 크기입니다.
  3. \(s = \int\sqrt2\,e^t\,dt = \sqrt2\,e^t\)이므로 \(t = \ln\frac{s}{\sqrt2}\)이다.여기가 틀렸습니다. \(t = 0\)에서부터 잰 길이는 정적분 \(s = \int_0^t\sqrt2\,e^u\,du = \sqrt2(e^t - 1)\)입니다. 그래서 \(t = \ln\left(1 + \frac{s}{\sqrt2}\right)\)입니다.
  4. 틀린 곳이 없다.\(t = 0\)일 때 \(s\)가 0이 되나요?
  1. 원 \(\vec{r}(t) = (2\cos 3t, 2\sin 3t)\)를 단위속력곡선으로 재매개화한다.문제입니다.
  2. \(|\vec{r}\,'(t)| = 6\)이므로 \(s = 6t\)이다.맞습니다.
  3. \(t = \frac{s}{6}\)을 넣으면 \(\vec{r}(s) = \left(2\cos\frac{s}{6}, 2\sin\frac{s}{6}\right)\)이다.여기가 틀렸습니다. \(3t = \frac{s}{2}\)이므로 \(\left(2\cos\frac{s}{2}, 2\sin\frac{s}{2}\right)\)입니다. 대입할 때 \(3t\) 전체를 바꿔야 합니다.
  4. 틀린 곳이 없다.결과의 속력이 1인지 확인해 보세요.
  1. 직선 \(\vec{r}(t) = (1 + 2t, 3 - t, 2t)\)를 단위속력곡선으로 재매개화한다.문제입니다.
  2. \(|\vec{r}\,'(t)| = \sqrt{4 + 1 + 4} = 3\)이므로 \(s = 3t\), \(t = \frac{s}{3}\)이다.맞습니다.
  3. \(\vec{r}(s) = \left(1 + \frac{2s}{3}, 3 - \frac{s}{3}, \frac{2s}{3}\right)\)이다.맞습니다. 방향 벡터가 단위벡터 \(\left(\frac{2}{3}, -\frac{1}{3}, \frac{2}{3}\right)\)가 되었습니다.
  4. 틀린 곳이 없다.맞습니다. 직선의 재매개화는 방향 벡터를 단위벡터로 바꾸는 것과 같습니다.

  1. 질문재매개화는 "속력 구하기 → 호의 길이 적분 → 역함수 → 대입" 네 단계입니다. 단계는 단순하지만 실수가 자주 나옵니다. 어디서 틀리기 쉬울까요?
  2. 복원\(|\vec{v}| = \sqrt{v_1^2 + v_2^2 + v_3^2}\), 정적분 \(\int_a^b f(u)\,du\)의 아래끝을 빼야 합니다.
  3. 설명흔한 실수는 ① 속력을 성분의 합으로 계산하기, ② 호의 길이를 부정적분으로 써서 시작점을 놓치기(\(s(t_0) = 0\)이어야 함), ③ 역함수를 대입할 때 식의 일부만 바꾸기입니다. 마지막에 \(\left|\frac{d\vec{r}}{ds}\right| = 1\)인지 확인하면 대부분의 실수를 잡을 수 있습니다.
  4. 연결재매개화한 곡선은 곡률 \(\kappa = \left|\frac{d^2\vec{r}}{ds^2}\right|\)을 바로 계산하는 데 씁니다(곡률).
  5. 적용네 풀이에서 처음 틀린 줄을 찾으세요. 찾으면 아래에 바른 결과와 속력 확인이 나타납니다.
  6. 판단로그 나선처럼 \(s(t)\)의 역함수가 깔끔하게 나오는 경우는 드뭅니다. 역함수를 식으로 쓸 수 없을 때는 수치로 구하고, 이론에서는 "단위속력 재매개화가 존재한다"는 사실만 씁니다.
