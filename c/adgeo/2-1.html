평면곡선의 매개변수 방정식

\(y = f(x)\)로 쓰기 어려운 곡선도 점의 위치를 하나의 변수 \(t\)의 함수 \((x(t), y(t))\)로 나타내면 쉽게 다룰 수 있습니다. 이것이 매개변수 방정식입니다. 이 절에서는 굴러가는 바퀴 위의 점이 그리는 사이클로이드와, 가로와 세로의 두 진동이 만드는 리사주 무늬를 매개변수로 그려 봅니다.

2.1.1

굴러가는 바퀴 위의 점은 어떤 곡선을 그릴까?

평면곡선의 매개변수 방정식 · 조작

  1. 질문자전거 바퀴 테두리에 붙은 반사판은 바퀴가 굴러갈 때 어떤 모양의 길을 그릴까요? \(y = f(x)\) 꼴로 쓰기 어려운 이런 곡선은 어떻게 식으로 나타낼까요?
  2. 복원반지름 \(r\)인 원이 각 \(t\)(라디안)만큼 미끄러지지 않고 굴러가면 중심은 호의 길이 \(rt\)만큼 앞으로 갑니다.
  3. 설명곡선 위의 점을 하나의 변수 \(t\)의 함수로 \((x(t), y(t))\)라 나타낸 것을 매개변수 방정식이라 합니다. 바퀴의 중심은 \((rt, r)\)이고, 중심에서 \(d\)만큼 떨어진 점은 중심에서 각 \(t\)만큼 돌아가 있으므로 \(x = rt - d\sin t\), \(y = r - d\cos t\)입니다. \(d = r\)이면 사이클로이드로, 땅에 닿는 순간 뾰족한 점(첨점)이 생깁니다. \(d < r\)이면 물결 모양, \(d > r\)이면 고리가 생깁니다.
  4. 연결사이클로이드를 뒤집은 미끄럼틀은 두 점 사이를 가장 빨리 내려오는 곡선(최속강하선)으로 유명합니다. 기차 바퀴는 레일 바깥으로 튀어나온 테가 있어서, 그 위의 점은 잠시 뒤로 움직입니다(\(d > r\)일 때의 고리).
  5. 적용바퀴를 굴리며 점이 그리는 곡선을 보세요. \(d\)를 바꾸면 모양이 어떻게 달라지나요? 사이클로이드 한 아치의 너비는 바퀴 둘레와 같나요?
  6. 판단매개변수 \(t\)는 시간일 수도, 각일 수도 있으며 곡선의 그림만으로는 알 수 없습니다. 같은 곡선도 매개변수를 바꾸면 다른 식이 됩니다(재매개화). 이 카드의 \(t\)는 바퀴가 돈 각입니다.

2.1.2

가로와 세로로 따로 흔들리는 점은 어떤 무늬를 그릴까?

리사주 곡선 · 만들기

  1. 질문오실로스코프에 두 소리 신호를 가로와 세로로 넣으면 화면에 아름다운 고리 무늬가 생깁니다. 무늬의 모양을 보고 두 소리의 높이(진동수)의 비를 알 수 있을까요?
  2. 복원\(\sin(t + 90°) = \cos t\)이고, \(\cos^2t + \sin^2t = 1\)입니다. \(\sin 2t = 2\sin t\cos t\)입니다.
  3. 설명\(x = \sin at\), \(y = \sin(bt + \varphi)\)로 나타나는 곡선을 리사주 곡선이라 합니다. \(a = b\)이면 위상차 \(\varphi\)에 따라 직선, 타원, 원(\(\varphi = 90°\))이 되고, \(a : b\)가 정수비이면 닫힌 곡선이 됩니다. 곡선이 세로선과 만나는 최대 개수와 가로선과 만나는 최대 개수의 비가 대략 \(b : a\)라서, 무늬를 보고 진동수 비를 읽을 수 있습니다.
  4. 연결오디오 장비에서 두 채널의 위상을 확인하거나, 전자 회로에서 두 신호의 주파수 비를 잴 때 리사주 무늬를 씁니다. 같은 곡선을 \(y\)를 \(x\)의 식으로 바꾸어 쓰면(예: \(a = 1, b = 2, \varphi = 90°\)이면 \(y = 1 - 2x^2\)) 포물선 조각이 됩니다.
  5. 적용목표 무늬마다 \(a\), \(b\), \(\varphi\)를 맞춰 보세요. 맞추면 성공이 표시됩니다. 같은 무늬를 만드는 다른 값도 있나요?
  6. 판단매개변수 곡선을 \(y = f(x)\)로 바꾸면 그림의 일부만 나타나거나(포물선 "조각"), 한 \(x\)에 여러 \(y\)가 대응해 함수가 아니게 됩니다. 매개변수 표현이 더 많은 곡선을 다룰 수 있는 이유입니다.
