2.3.1

정사각형 바닥 둘레에 까는 테두리 타일은 몇 장일까?

대응 관계와 규칙 · 만들기

가운데에 한 변이 \(n\)장인 정사각형 바닥 타일을 깔고, 그 둘레를 한 줄의 테두리 타일로 두릅니다(타일 시공 예시).

내가 찾은 규칙: 테두리 타일 수 = × n +

  1. 질문타일 시공자는 바닥 크기만 듣고 테두리 타일 수를 바로 계산합니다. 한 변이 \(n\)장일 때 테두리 타일 수를 식으로 나타낼 수 있을까요?
  2. 복원두 양 \(x, y\)가 짝지어 변할 때, \(x\)의 값마다 \(y\)의 값이 하나씩 정해지면 대응 관계라 하고 \(y = ax + b\)처럼 식으로 나타낼 수 있습니다.
  3. 설명표를 만들면 \(n = 1, 2, 3, \ldots\)일 때 테두리 타일이 8, 12, 16, …으로 4씩 늡니다. 네 변에 \(n\)장씩, 네 모서리에 1장씩이므로 \(4n + 4\)입니다. 같은 수를 \(4(n + 1)\)이나 \((n + 2)^2 - n^2\)처럼 다르게 셀 수도 있고, 모두 같은 식입니다. 일정하게 늘어나는 양은 일차식으로 나타낼 수 있습니다.
  4. 연결의자 배치, 울타리 기둥 수, 계단 수처럼 규칙이 있는 배치는 대응표를 만든 뒤 식으로 일반화합니다. 다음 카드에서는 근무 시간과 급여의 대응을 다룹니다.
  5. 적용규칙을 식으로 적어 확인해 보세요. 한 변이 25장인 바닥에는 테두리 타일이 몇 장 필요할까요?
  6. 판단모서리를 두 번 세거나 빼먹는 실수가 흔합니다. 작은 경우(\(n = 1\))를 직접 세어 식이 맞는지 확인하면 실수를 잡을 수 있습니다.

2.3.2

밤에 일하는 시간이 늘면 하루 급여는 어떻게 늘어날까?

대응 관계와 규칙 · 활용

시급과 "야간 시간은 1.5배"라는 조건은 수업용 가정입니다. 실제 근로 조건은 법과 계약에 따릅니다.

  1. 질문편의점에서 하루 8시간 일하는데 그중 일부가 야간 시간이면 1.5배를 받습니다. 야간 시간이 1시간 늘 때마다 하루 급여는 얼마씩 늘까요?
  2. 복원\(y = ax + b\)에서 \(x\)가 1 늘면 \(y\)는 \(a\)만큼 늡니다.
  3. 설명근무 시간 8시간 중 야간 \(x\)시간, 주간 \((8 - x)\)시간이면 급여는 \(y = 10000(8 - x) + 15000x = 80000 + 5000x\)입니다. 야간 1시간은 주간 1시간을 대신하므로 늘어나는 것은 15000원이 아니라 차이인 5000원입니다. 대응표를 만들어 보면 \(y\)가 5000원씩 일정하게 늘어 그래프가 직선이 됩니다.
  4. 연결택시 요금, 주차 요금, 휴대폰 요금처럼 기본값과 단위당 값이 있는 대응은 모두 일차식입니다. 다음 절에서는 변화를 그래프로 읽습니다.
  5. 적용시급과 근무 시간을 바꿔 가며 야간 1시간당 늘어나는 금액을 확인하세요. 그 금액은 무엇에 따라 정해지나요?
  6. 판단야간 시간이 하루 근무 시간을 넘을 수는 없습니다. 식은 \(0 \le x \le 8\)에서만 의미가 있습니다. 대응 관계의 식을 쓸 때는 변수의 범위도 함께 정해야 합니다.
