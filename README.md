# 나뭇잎 디지털 교과서

생략된 설명과 연결을 복원하는 고등학교 수학·과학 디지털 교과서입니다.
2022 개정 교육과정의 과목·대단원·절마다 직접 조작해 보는 개념 카드가 있습니다.

**바로 보기: https://radix24.github.io/namunnip-textbook/**

### 과목

- **과학 공통:** 통합과학1·2, 과학탐구실험1·2
- **일반선택:** 물리학, 화학, 생명과학, 지구과학
- **진로선택:** 역학과 에너지, 전자기와 양자, 물질과 에너지, 화학 반응의 세계, 세포와 물질대사, 생물의 유전, 지구시스템과학, 행성우주과학
- **과학계열:** 고급 물리학·화학·생명과학·지구과학, 과학과제 연구, 정보과학, 물리학·화학·생명과학·지구과학 실험
- **융합선택:** 과학의 역사와 문화, 기후변화와 환경생태, 융합과학 탐구
- **수학:** 공통수학1·2, 대수, 미적분Ⅰ, 확률과 통계, 미적분Ⅱ, 기하

## 특징

- **여섯 단계 카드:** 질문 → 복원 → 설명 → 연결 → 적용 → 판단. 그림을 직접 조작해서 개념을 발견하고, 마지막에 오개념과 모형의 한계를 짚습니다. 실험 카드는 가상 측정·기록 표·그래프 분석까지 합니다.
- **확인 문제:** 조건을 바꾼 새 상황으로 묻고, 오답마다 왜 그럴듯한지와 왜 틀렸는지를 설명합니다.
- **개념 지도** (`graph.html`): 개념과 블록, 선수 관계를 그래프로 보여 주고, 학습 진도에 따라 색이 바뀝니다.
- **내 노트** (`notes.html`): 메모, 형광펜, 오답노트를 브라우저에 저장하고 내보내기·가져오기로 백업합니다. 서버나 계정은 없습니다.
- **연습문제** (`practice.html`): 절마다 관련 기출 문항을 모아 봅니다.
- **오프라인 앱:** 설치형 웹앱(PWA)이라 한 번 열면 인터넷 없이도 모든 절을 볼 수 있습니다.
- **외부 라이브러리 없음:** 그림은 모두 Canvas·SVG로 직접 그리고, 수식만 KaTeX를 씁니다.

## 구조

교과서는 **블록**을 **교육과정 배치표**에 끼워 만듭니다. 교육과정이 바뀌면 배치표만 새로 만들면 되고, 블록 id가 그대로라 학생의 노트와 진도도 유지됩니다.

```
blocks/<과목>/<블록 id>.html   내용 한 조각 (카드·읽기·영상·절 소개)
js/cards/<과목>/*.js           카드 스크립트
curricula/2022.json            과목 → 대단원 → 절 → [블록 id]
graph/concepts.txt             개념과 선수 관계 (개념 지도 데이터)
basics/                        중학교 선수 개념 설명
exams/                         기출 문항 색인과 이미지 (이미지는 Git LFS)
tools/build.py                 → c/**/*.html, js/toc.js, sw-files.js 생성
```

`c/` 아래 절 페이지와 `js/toc.js`, `js/graph-data.js`, `sw-files.js`는 빌드가 만드는 파일이므로 직접 고치지 않습니다.

## 만들기

```bash
python3 tools/build.py                        # 페이지·목차·개념 지도·오프라인 목록 생성
python3 tools/check.py 8811 c/earth/1-6.html  # 콘솔 오류와 404 검사
```

블록 형식, 카드 작성 규칙, 내용 원칙은 [BUILD.md](BUILD.md)에, 진행 기록은 [ROADMAP.md](ROADMAP.md)에 있습니다.

## 배포

`main`에 푸시하면 GitHub Actions(`.github/workflows/pages.yml`)가 LFS 이미지를 받아 GitHub Pages에 올립니다.
저장소 **Settings → Pages → Build and deployment → Source**가 **GitHub Actions**로 되어 있어야 합니다.
